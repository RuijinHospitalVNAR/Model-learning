## 1. 学习背景与目标

本仓库专题主线是"全原子表示 vs 全原子生成"。ATOMICA 属于最容易被误读的一类：它确实以**原子为最小节点**建模蛋白、小分子、金属离子、脂质、核酸五类模态，但它的产出是**界面表征与交互预测**，不是结构生成。

本次学习要回答四个问题：

1. 它说的"全原子"到底到哪一层（氢？电荷？键级？侧链构象？）；
2. 架构能否复现到超参级别（层数、通道、近邻、噪声、目标函数）；
3. 训练数据与切分是否支撑"跨模态泛化"这一核心宣称；
4. 对 VNAR/纳米抗体这条线，哪些能直接用、哪些不能用。

## 2. 核心概念

| 术语 | 含义 |
| ---- | ---- |
| 五模态 / 八交互类型 | 蛋白、小分子、金属离子、脂质、核酸；交互类型含蛋白-蛋白、蛋白-小分子、蛋白-离子、蛋白-肽、蛋白-核酸、核酸-配体等 |
| atom-level graph | 每个重原子一个节点，特征 = 元素 one-hot（118 类）+ 3D 坐标；同分子/跨分子各取 k 近邻建边 |
| block-level graph | 每个块（蛋白残基、化学片段、元素、离子）一个节点；块坐标 = 块内原子坐标均值 |
| 全局节点 | 每个 segment 一个 global block；`global_message_passing` 打开时参与块级消息传递 |
| 去噪得分匹配 | 对随机选中的一个 segment 施加刚体旋转/平移与侧链扭转噪声，网络回归对应的 score（不是回归坐标） |
| 掩码块身份预测 | 随机 10% 块被替换为 mask 类型，预测其原始块类型（交叉熵） |
| `h` / `z` 表征族 | `h` = 单位化后的隐向量（32 维/块）；`z` = 由不可约表示构造的不变描述子（块级 1792 维） |
| z_block | 32（标量通道）+ 544（l>0 不变量）+ 1216（块内原子不变量池化）= 1792 |
| ATOMICA-Interface | 用 8 Å 界面裁剪图与完整复合物图表征做对比对齐微调，使界面图与复合物图表征同空间 |
| ATOMICA-Ligand | 对 9 种金属离子、12 种小分子各训一个二分类头，判断某口袋是否结合该化学实体 |
| ATOMICAScore | 逐块 mask 后看交互 logit 下降量，作为该残基/片段对界面贡献的归因分数 |
| ATOMICANet | 以界面表征余弦相似度建网（每模态一张），用于疾病模块与随机游走靶点提名 |

## 3. 原理与推导

### 3.1 基本假设

界面功能主要由**局部几何 + 元素身份 + 块级化学语义**决定；因此不需要显式键图、电荷或质子化状态，靠 SE(3) 等变消息传递即可从坐标中学到相互作用模式。【代码／配置核实：`pdb_utils.py` 只编码元素与坐标，边特征仅 4 类关系标签；距离通过 GaussianEmbedding 进入等变层】

### 3.2 图构造

- **原子节点**：元素 one-hot（118 类元素表）+ xyz。氢原子与水被显式过滤（`pdb_utils.py`：注释为"not all data include them"），因此"全原子"实测为**全重原子**。
- **块节点**：蛋白 = 20 种氨基酸残基；DNA/RNA = 4+4 种核苷酸；小分子 = PS_300 片段词表（300 个 token，正文称其中约 290 个为常见化学基元，其余为特殊块：mask / unknown / global / 边界符等）；CSD 预训练阶段先以元素为块，再经 `atom_blocks_to_frag_blocks.py` 片段化。
- **边**：同分子内 k 近邻 + 跨分子 k 近邻；块级边按"两块间最小原子距离"取 k 近邻；`k=8`（发布配置）。边属性只有 4 类：intra / inter / global-global / global-normal。【代码／配置核实】
- **距离编码**：`max_edge_length=5 Å`（atom 与 block 层），GaussianEmbedding 32 个高斯基；没有显式键长/键角/键级特征。

### 3.3 等变主干

- `InteractionModule` 的 irreps 为 `0e, 0o, 1o, 1e, 2e, 2o`，即内部 **lmax = 2**；输入原子特征为标量，论文"λmax=1 for h_atom"指输入层，正文随后又说"每层后过滤到 λmax=2"，两句话不矛盾但容易被读成冲突。【代码／配置核实；论文表述有歧义】
- 发布配置：`atom_hidden_size=32`、`block_hidden_size=32`、`edge_size=32`、`n_layers=4`；`n_layers` 同时用于 atom-level 与 block-level 两个 encoder，因此**实际共 8 个消息传递阶段**（4+4），而论文超参搜索里的 L∈{4,6,8} 指的是每层数量还是总数，正文未写清。【代码／配置核实 + 推断】
- 层间接口：atom 层输出经 `CrossAttention(block←atom)` 汇入块节点；块级 encoder 再跑 4 层；图级读出用 4 层 4 头 `AttentionPooling`（`scatter_sum` + Linear + L2 normalize）。
- 参数量：仓库文档给出 8.4 M（MaSIF-ligand checkpoint 说明）。【代码／配置核实（仓库文档）】

### 3.4 预训练目标

论文写法（Methods 3）：

`L = βω·L_rot + βt·L_trans + βθ·L_tor + βm·L_mask`

- 论文只给 `βω=1, βt=1, βm=0.1`，**βθ 未给值**；代码默认 `tor_weight=1.0`，发布脚本未覆盖。
- 发布脚本 `scripts/pretrain.sh` 反而设置 `--rot_weight 0.1`（与 βω=1 不一致），且未设 `--mask_weight`（取默认 1.0，与 βm=0.1 不一致）。见 §5.2。
- 噪声采样（`utils/noise_transforms.py`）：旋转用 IGSO(3)，从 100 个离散角度 bin 中采样并在 `max_rotation=0.5` 处截断，`σ_rot=0.25`；平移噪声尺度 `ε~U(0.1, σ_t)`、`σ_t=1`，目标 score 取单位高斯；扭转仅对蛋白侧链可旋转键施加，`σ_θ=0.5`，回归 3 维轴角 score，只用键中心 5 Å 内原子。
- **每次只扰动两个 segment 中的一个**（`chosen_segment` ∈ {0,1}），另一侧保持干净；掩码施加在**未被扰动的一侧**，避免两类噪声互相干扰。【代码／配置核实】
- 推理无噪声、无 mask，单次前向；**没有扩散/流匹配的反向采样链**，也没有坐标解码器。

### 3.5 变长原子与掩码的实现细节

- 块内原子数可变，用 per-block 原子列表 + attention pooling 汇总，块坐标取原子均值。
- **掩码块会把整块原子塌缩为 1 个位于块质心的 mask 原子**（`dataset_pretrain.py`：`block_lengths=1`，`masked_A` 追加一个 mask 原子类型）。论文 Methods 只写"块身份被替换为 mask block"，未提几何塌缩，属于**描述不完整**。这也意味着 ATOMICAScore 评估时会同时移除该残基的全部原子，而非仅隐藏标签。

## 4. 训练数据构成与切分

### 4.1 数据源与规模

| 数据源 | 规模 | 说明 |
| ---- | ---- | ---- |
| CSD（小分子晶体） | 1,767,710 个分子对 / 375,941 条目 | 筛选：有机、非聚合、有 3D 坐标、无无序、无错误、无金属、单一 SMILES、6–50 个重原子；以 4 Å 截取中心构象与外围构象的接触对 |
| Q-BioLiP（2024-06） | 337,993 个复合物 | 蛋白-蛋白 124,541；蛋白-小分子 119,017；蛋白-离子 74,514；蛋白-肽 8,475；核酸-配体 5,185；蛋白-RNA 3,511；蛋白-DNA 2,750 |
| 合计 | 2,105,703（按 Methods 相加） | 摘要写 2,037,972，见 §5.2 冲突 1 |

【核实：数字取自 Methods "Curation of datasets"】

### 4.2 清洗与去重

- CSD：按条目级过滤（见上表），未报道按分子指纹去重；接触对抽样本身会产生同一晶体内大量近重复对，论文未量化去重比例。【未核实】
- Q-BioLiP：蛋白/DNA/RNA 统一裁剪到"距对侧任意原子/残基 8 Å"的界面；不保留体相溶剂与远端区域。
- 去冗余：按模态做 MMseqs2 30% 序列相似度聚类（coverage 80%、sensitivity 8、cluster mode 1）；蛋白-蛋白额外要求跨簇任意两条链均 ≤30%；蛋白-核酸同时按蛋白 30% 与核苷酸 30% 聚类；核酸-配体按核苷酸 30% 聚类。【核实（论文描述）；脚本未随仓库发布，无法复跑 → 该步为【未核实：实现】】

### 4.3 切分与泄漏控制

- Q-BioLiP：按**簇**做 8:1:1 切分（train/valid/test），不是按复合物随机切分。【核实】
- CSD：用 290 个化学基元 one-hot 的 Manhattan 距离，抽 1,000 个复合物及其各 100 个最近邻，分别构成 10,000 个验证与 10,000 个测试复合物，要求"与训练集不同"。注意：**只保证复合物不同，不保证与训练集近邻不相似**——最近邻抽样会系统性偏向相似样本，因此该测试集更接近"细粒度判别"而非"分布外泛化"。【核实 + 推断】
- 下游基准普遍采用"排除重叠数据后重训"的做法：MaSIF-ligand 用移除 29,094/105,090 个蛋白-配体训练复合物的 checkpoint；RNA-Site 用排除核酸-配体复合物的 checkpoint；RNA-Protein 用排除蛋白-RNA 的 checkpoint。这说明**通用权重在这些基准上存在训练集污染**，作者用消融 checkpoint 规避。【代码／配置核实（仓库 checkpoint 说明）】

### 4.4 覆盖与偏置

- CSD 只保留 6–50 重原子的有机小分子、且排除金属，因此对大面积疏水配体、金属配合物、共价修饰残基覆盖弱。
- Q-BioLiP 的蛋白-肽仅 8,475 条，是五类里最少的；蛋白-DNA 仅 2,750 条。
- **没有专门的抗体/纳米抗体数据层**；抗体-抗原复合物只作为蛋白-蛋白的一小部分存在，且 CDR 柔性在结构数据库中被作者明确列为覆盖不足区域（Discussion）。【核实】
- 物种偏置：未按物种分层报道。【未核实】

### 4.5 可获取性与许可

- 预处理图数据：Harvard Dataverse，DOI `10.7910/DVN/4DUBJX`（含预训练集、RNAglib 四任务、MaSIF-ligand、ATP/ADP、pocket retrieval、PPI 抑制剂、暗蛋白界面）。
- 权重：Hugging Face `ada-f/ATOMICA`（预训练 + 12 个小分子/9 个离子头 + MaSIF 去污染 checkpoint + RNA 消融 checkpoint）。
- 代码：GitHub `mims-harvard/ATOMICA`，MIT 类许可需以仓库 LICENSE 为准（本地包未逐行核对许可证文本）。【未核实：许可证细则】

### 5.3 可复现所需材料

- 权重：HF 公开（预训练 + 任务头 + 消融 checkpoint），可复现推理。
- 数据：Dataverse 提供预处理图，但 **MMseqs2 聚类与切分的脚本不在仓库**，无法从原始 PDB/CSD 复跑数据构建。【未核实：数据管线实现】
- 算力：预训练 4×H100；单任务头微调 1×H100 / 50 epochs。
- 关键复现陷阱：`h_graph` / `h_interface` 用 attention pooling，**批次组成会改变数值**，代码显式禁止 batch>1（`representations.py` 抛错）。做跨样本比较必须固定 batch=1 与样本顺序。【代码／配置核实】

## 6. 实践与应用

### 6.1 可直接使用的接口

- 表征提取：`representations.py` 提供 8 个命名表征（`h_atom/h_block/h_graph/h_interface`、`z_atom/z_block/z_graph/z_interface`）。
  - 需要给下游头训练：用 `mean_std_global`（块宽 ×3，5,376 维）。
  - 需要冻结表征直接比相似度：用 `mean_component_normalized`（1,792 维），先按分量归一化再池化。
  - **两种池化不可混用**，代码故意不设默认值。
- 打分：ATOMICAScore 通过逐块 mask 计算 Δlogit；也可用 `z_graph` 余弦做复合物级相似度。
- 口袋注释：ATOMICA-Ligand 每类化学实体一个头，阈值在验证集上按 F1 最大化选取（限制在 0.05–0.95）。

### 6.2 对 VNAR / 纳米抗体的可迁移点

**能做的：**

1. 把 VNAR-抗原复合物当作"蛋白-蛋白界面"直接编码：VNAR 是单域，链归属清晰（segment 0/1），比 scFv 更少链配对歧义。
2. 用 `z_interface` 做**表位/副位相似性检索**：相同表位、不同框架的结合体在界面表征上应更近；可用于表位聚类与交叉反应初筛。
3. 用 ATOMICAScore 对抗原位点做归因排序，作为丙氨酸扫描前的先验（注意：只是排序信号，见 §6.3）。
4. 把 `z_graph`/`z_interface` 作为轻量特征，接一个线性/MLP 头做亲和力分级或结合/不结合分类；参数少，小样本友好。

**不能做的（必须写清）：**

1. **不能生成**：无解码器、无扩散/流匹配采样，无法产出 VNAR 序列或结构；只能对已存在的结构打分/编码。
2. **不能做序列条件预测**：输入是坐标，不是序列；CDR3 设计、框架人源化都无法直接表达。
3. **对 CDR 柔性无建模能力**：作者自己把抗体 CDR 与 IDR 列为结构输入的主要失效区；VNAR 的 CDR3 往往更长、更柔性，这是硬约束。
4. **没有化学细节**：无氢、无质子化/电荷、无键级、无芳香性，无法区分组氨酸质子化态、盐桥方向、卤键等对亲和力关键的效应。
5. **没有抗体专属训练信号**：Q-BioLiP 中抗体-抗原占比未披露，且预训练目标是通用界面去噪，不保证对 paratope 语法敏感。
6. **跨模型比较要谨慎**：仓库给的 RNA/MaSIF 数值来自"排除该模态"的消融 checkpoint，不是通用权重；与其它模型对比时 checkpoint 不同源。

### 6.4 环境与常见坑

- 依赖 PyTorch 2.1.1 + PyTorch Geometric 2.1.1；预训练脚本按 SLURM 写死 `#SBATCH` 与 conda 绝对路径，需改写。
- `--gpu` vs `--gpus` 的 argparse 不一致（§5.2 第 7 条），照抄脚本会失败。
- `h_graph`/`h_interface` 必须 batch=1；`z_*` 可批量。
- 输入 PDB 需要链级 segment 标签；两条链以上的复合物需先明确"哪条是 VNAR、哪条是抗原"。

## 7. 疑问与讨论

- **Q**：ATOMICA 能不能算"全原子生成模型"的 baseline？
  - **A**：不能。它没有生成头、没有采样过程；论文 Discussion 明确写"can serve as a foundation for generative models"。放在生成模型综述里，应归入"全原子表征/打分器"而不是"生成器"。

- **Q**：它是否真的"全原子"？
  - **A**：节点粒度是原子，但只有重原子（H 与水被过滤），且没有键级、电荷、芳香性、质子化。严格说是"元素标注的原子点云 + 块级化学语义"，比"全原子力场"粗，比"残基级"细。

- **Q**：掩码预训练是不是会泄漏标签？
  - **A**：掩码只作用于未被扰动一侧，且被掩码块塌缩为单原子，模型无法从被掩码块自身读到身份；但**可以从对侧界面几何推断**，这正是任务设计意图，不算泄漏。

- **Q**：仓库教程给的 RNA 数值能不能引用？
  - **A**：只能标注"仓库文档值，正文未载"。下载的 v2 正文与 XML 都不含 RNAglib/MaSIF 字样，无法核实其"published"归属。

## 8. 学习心得

### 8.1 反直觉发现（本笔记最有价值的部分）

1. **"全原子"标签不等于"全原子生成"**：ATOMICA 是表征/打分模型，无解码器、无采样链；作者自己在 Discussion 里把它定位为生成模型的"基础"。
2. **"全原子"实测是"全重原子"**：代码过滤氢与水；118 类元素 one-hot 是唯一的化学身份信息，没有键级/电荷/芳香性。对需要质子化态或卤键的场景，这一层信息永久缺失。
3. **掩码不只换标签，还把整块原子删成一个质心点**：论文 Methods 写"替换块身份"，代码把 `block_lengths` 置 1、只留一个 mask 原子。做 ATOMICAScore 归因时，这等于同时移除该残基的几何，Δlogit 的含义比"遮挡标签"更强。
4. **数据总量在摘要与 Methods 之间差 6.8 万**：2,037,972 vs 2,105,703；两个分项也都不同。引用规模时必须注明取自哪一节。
5. **CSD 版本号正文自相矛盾**：Results v2022.3.0，Methods v2023.2.0。
6. **发布脚本与论文超参三处不一致，且脚本本身跑不起来**：200 vs 150 epochs、rot_weight 0.1 vs βω=1、mask_weight 默认 1.0 vs βm=0.1；`--gpu` 与 `--gpus` 不匹配。
7. **仓库文档描述的"论文 Figure 3/4"在正文里不存在**：正文 Fig. 3 是界面组网络、Fig. 4 是暗蛋白；RNAglib、MaSIF-ligand、ATP/ADP、pocket retrieval、metal coordination 全部只在仓库教程中出现。说明代码/教程对应的是另一个稿件版本，引用这些数值必须降级为"仓库文档值"。
8. **ATOMICAScore 的 headline 效应量很小**：benchmark 上是 2.7/10 vs ESM-2 2.4/10 vs 随机 2.0/10；而仓库教程单复合物演示给到 0.800。**单例演示 ≠ 基准均值**，这是最容易被二手引用放大的地方。
9. **最有效的表征不是 32 维 `h_block`，而是 1,792 维 `z_block`**：RNA-Site 上 0.135→0.243（p=0.0078）。用 32 维向量做检索会系统性低估模型能力，也会让"嵌入很小很轻量"的说法失真。
10. **暗蛋白注释的分母不是看起来那个数**：969 个 PeSTo 小分子位点里只有 81 个（8.4%）被标上化学身份，2,851 个离子位点里 2,565 个（90.0%）。"2,646 个位点被注释"不能读成"2,646 个分子被鉴定"。
11. **跨模态基准用的是消融 checkpoint，不是通用权重**：MaSIF-ligand 移除 29,094/105,090 个训练复合物后重训；RNA-Site/RNA-Protein 各用"排除对应模态"的 checkpoint。直接把通用权重跑同一基准会因泄漏而偏高，跨模型对比必须核对 checkpoint 来源。
12. **同配体口袋检索很弱**：mAP 0.061、AUROC 0.622、Hit@20 0.326。说明"界面相似 = 功能相似"在跨蛋白、同配体场景下只有有限成立，不能当通用功能检索器。

### 8.2 一句话定位

ATOMICA = **重原子级、元素-only 化学、块级语义、SE(3) 等变、双层图 + 去噪/掩码自监督的界面表征与打分器**；它的强项是跨模态界面的统一嵌入与疾病/暗蛋白层面的规模化注释，弱项是化学细节、柔性区域、以及"生成"这件事本身。
