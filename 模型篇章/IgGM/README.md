## 1. 学习背景与目标

抗体/纳米抗体设计在“序列 + 结构 + 抗原特异性”三个层面同时受约束：只做序列逆折叠（AntiBMPNN 一类）拿不到复合物构象，只做结构预测（AF3 一类）又不会主动选序列。IgGM 的定位正是把这两步合成一个条件生成问题——**给定抗原，联合生成抗体序列与抗体-抗原复合物结构**。

本次目标：

1. 判断 IgGM 是“生成模型”还是“结构预测器”，以及它在三轴（表征粒度 × 生成范式 × 条件接口）里的真实坐标；
2. 搞清它的数据是否覆盖单域重链/VNAR，从而判断对鲨源 VNAR 的可迁移性；
3. 分清论文自称与可复现证据，给后续做 VNAR 设计时“能不能直接拿来用”一个明确结论。

## 2. 核心概念

| 术语 | 含义 |
| ---- | ---- |
| IgGM | Immunoglobulin Generative Model，腾讯 AI4S 的抗体/纳米抗体联合生成模型，ICLR 2025【核实：proceedings.iclr.cc 论文页】 |
| 残基 frame | 每个残基的局部坐标系（Cα 位置 + 主链朝向），IgGM 把它作为 SO(3) 上的生成变量 |
| 离散扩散 | 在 20 种氨基酸的类别空间上做加噪/去噪，转移矩阵随噪声 schedule 变化 |
| Consistency model | 把多步扩散蒸馏成少步（甚至一步）采样的加速手段，训练时让学生网络回归教师轨迹 |
| Sgformer | IgGM 的序列-结构主干，16 层，同时维护单序列与配对表示 |
| IPA | Invariant Point Attention，把标量特征与残基 frame 绑定的等变注意力（AF2 系） |
| epitope 条件 | 指定抗原上哪些残基参与界面，作为生成时的软/硬约束 |
| 掩码模式 | 指定哪些 CDR（或 CDR 组合）要被重新生成，其余残基固定 |

## 3. 原理与推导

### 3.1 一句话结构

IgGM = **冻结的 ESM-PPI 序列特征** + **Sgformer 主干** + **8 个预测模块**，每个模块带 IPA，输出三类变量：序列 logits、Cα 坐标、残基 frame（SO(3)）。三类变量各自走一条扩散过程，再用 consistency 蒸馏把采样步数压下来。【论文自称；架构细节见原文 §3 与附录】

### 3.2 表征粒度：主链级，不是全原子

- 显式建模的原子只有主链 **N、Cα、C、O**，输出是主链坐标 + 残基朝向 + 序列；**侧链原子不生成**，也没有 χ 角变量。【核实：原文表征定义段】
- 这使它在“表征粒度五档”里落在 **Cα 单点／残基级**，而不是“全原子坐标”。矩阵里“无侧链，不能算全原子”的批注是准确的。
- 实践后果：IgGM 输出的复合物可直接做界面评价，但要拿去算结合能、做侧链优化，必须外接侧链 packing（论文的 baseline 对比里也用了外部侧链工具）。

### 3.3 生成过程：三条扩散 + 一致性蒸馏

设残基 i 的变量为 $(s_i, x_i, O_i)$：$s_i\in\{1..20\}$ 为氨基酸，$x_i\in\mathbb{R}^3$ 为 Cα，$O_i\in SO(3)$ 为 frame 朝向。

1. **序列**：离散扩散，前向按转移矩阵加噪，反向网络预测干净类别，损失为带噪权重的交叉熵；
2. **Cα**：高斯扩散，反向预测噪声/干净坐标，损失在主链对齐后计算；
3. **朝向**：SO(3) 上的扩散（IGSO3 一类），损失为 frame 旋转偏差；
4. **consistency**：在扩散模型之外训练一致性映射，使少步采样逼近多步结果。【论文自称】

> 注意：这不是“先预测结构再逆折叠”的两段式，而是**同一网络同时去噪三类变量**；因此序列与结构在生成过程中互相约束，这是它与 AF3+ProteinMPNN 流水线的本质差别。【推断，依据 §3 的联合损失设计】

### 3.4 条件接口：抗原 + 表位 + 框架 + 掩码

| 条件 | 接入方式 | 证据 |
| ---- | ---- | ---- |
| 抗原序列/结构 | 作为固定 context 参与注意力；抗原坐标在扩散中保持不动 | 【论文自称】 |
| 表位残基 | 显式标记界面残基；消融显示去掉后界面指标下降 | 【论文自称，消融】 |
| 框架序列 | 固定 framework，只对指定 CDR 加噪/生成 | 【论文自称】 |
| 掩码模式 | 可一次生成全部 6 个 CDR，也可只生成 H3 | 【核实：原文“simultaneously designing all six CDR regions”】 |
| 配对链 | 支持重/轻链配对与单链（纳米抗体）两种输入 | 【论文自称】 |

**抗原刚性**是重要限制：抗原坐标全程固定，不允许抗原在结合时发生构象调整。对抗原柔性问题（如 gp120、PD-L1 的构象选择）这会引入系统偏差。【推断，依据“抗原作为固定 context”的实现】

### 3.5 三轴定位

| 轴 | 取值 | 说明 |
| ---- | ---- | ---- |
| 表征粒度 | Cα 单点／残基级 | 主链 N/Cα/C/O + frame；无侧链 |
| 生成范式 | 扩散（+ consistency 蒸馏） | 离散序列扩散 + 连续 Cα 扩散 + SO(3) 扩散 |
| 条件接口 | 抗原结构 + 表位 + 框架 + 掩码 | 属“结构条件 + 残基级掩码”，不是 MSA/模板条件 |

## 4. 训练数据构成与切分

- **数据源与规模**：SAbDab，截止 **2022-12-31**；**6,448 个配对抗体-抗原复合物 + 1,907 个单链抗体-抗原复合物**。【核实：原文数据段】
- **清洗与去重**：CD-HIT 95% 序列相似度聚类，得到 **2,436 个簇**；按簇切分以避免同源泄漏。【核实：原文数据段】
- **切分与泄漏控制**：训练用 ≤2022 数据；测试用 **SAb-23H2**（2023 下半年新沉积）。抗体测试集 **60 个复合物**，纳米抗体测试集 **27 个复合物**。【核实：原文结果段】
- **覆盖与偏置**：
  - 单链集在论文中只称 “single-chain antibody–antigen complexes”，**未说明是否全部为 VHH/纳米抗体**；是否含鲨源 VNAR 未披露。【未核实：查过原文数据段与附录，未见 VNAR/IGHNAR 字样】
  - SAbDab 本身偏人/鼠 IgG，骆驼科 VHH 有少量，鲨源 IgNAR 极稀疏。即使单链集含 VHH，VNAR 的先验覆盖也接近零。【推断，基于 SAbDab 的已知构成】
  - 抗原种类受 SAbDab 收录偏置影响，膜蛋白、糖基化抗原覆盖不足。【推断】
- **可获取性与许可**：代码 MIT（`TencentAI4S/IgGM`，GitHub API 核实）；权重按矩阵记为 CC-BY、托管于 Zenodo 16909543。【代码许可：核实；权重许可：未核实，未下载权重包核对 LICENSE】

## 6. 实践与应用

- **适用场景**：已有抗原结构、希望一次拿到“序列 + 复合物构象”的 CDR 设计；纳米抗体/VHH 的 CDR 重设计；作为 AF3/ProteinMPNN 流水线的替代初筛。
- **前提条件**：抗原结构质量决定上限；抗原需刚性假设可接受；框架序列需已知；侧链与结合能需外接工具。
- **关键参数**：
  - 掩码策略：全 CDR 联合生成多样性高但恢复率低；只生成 H3 更稳。
  - 采样步数：consistency 蒸馏后可用少步；步数过少会牺牲界面精度。【论文自称】
  - AF3 初始化：用 AF3 预测结构作为扩散起点，可把 DockQ SR 从 43.3% 提到约 46.7%。【核实：原文 + 表格】
- **示例流程（伪代码）**：

```text
input: antigen.pdb, framework.fasta, mask = [H1,H2,H3,L1,L2,L3], epitope = [..]
1. 用 ESM-PPI 编码抗原与框架序列
2. 初始化 Cα/frame（随机或 AF3 预测）
3. 三类变量联合反向扩散 T 步（或 consistency 少步）
4. 输出序列 + 主链复合物；外接 side-chain packing
5. 用 AF3/几何指标复筛，再做湿实验
```

## 7. 疑问与讨论

- **Q**：IgGM 到底算不算“全原子模型”？
  - **A**：不算。它只显式生成主链 N/Cα/C/O 与残基朝向，侧链完全缺失。放在全原子矩阵里只能作“主链级对照”，不能与 AF3/Boltz 系逐项横比。【核实：表征定义】

- **Q**：为什么它能“同时”生成序列和结构，而 AF3 不能设计？
  - **A**：AF3 的条件是 MSA/模板，序列是输入而非变量；IgGM 把序列 token 也当作扩散变量，并让抗原作固定 context，所以序列与坐标在同一去噪过程里耦合。【推断，依据方法设计】

- **Q**：对鲨源 VNAR 能不能直接用？
  - **A**：**接口可迁移，先验不可迁移**。IgGM 的单链模式、CDR 掩码、表位条件在形式上适配 VNAR（单域、无轻链）；但训练集是 SAbDab 的抗体/VHH，几乎不含 IgNAR，VNAR 特有的长 CDR3、额外的 CDR1/框架二硫键、缺失的 CDR2 都不在分布内。合理用法是“用 IgGM 做结构支架与界面采样，再用 VNAR 专属数据/打分重排”，而不是直接相信它的 VNAR 序列先验。【推断 + 数据核查结论】

- **Q**：抗原刚性会不会毁掉柔性抗原的设计？
  - **A**：会。建议对柔性抗原先做多构象采样，分别条件生成，再按构象一致性筛选。【推断】

## 8. 学习心得

- IgGM 的价值不在“又一个扩散模型”，而在**把序列设计写成结构生成的一个变量**；这让“设计出来的序列是否折得成”不再依赖事后 AF3 检验。
- 主链级表征是它最大的工程优势（快、稳），也是它最大的科学缺口（侧链/结合能不可信）。做 VNAR 项目时应把它定位为“界面几何生成器”，而不是“亲和力预测器”。
- 数据截止 2022 与 SAbDab 偏置意味着：任何 2023 年后的新抗原/新格式都要重新评估分布外风险。
