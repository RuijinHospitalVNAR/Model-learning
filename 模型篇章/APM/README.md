## 1. 学习背景与目标

APM 是字节跳动 Seed 与湖南大学、国科大合作的工作（ICML 2025，arXiv 2504.13075v3），要解决的问题很明确：**现有蛋白基础模型几乎都只做单链**，而真实功能蛋白以复合物形式存在，链间相互作用发生在原子层面，仅靠主链 Cα 或残基级建模抓不住。

它被放进本仓库矩阵，是因为它同时踩在三条线的交点上：

1. **复合物生成**——从噪声直接生成有结合能力的多链复合物；
2. **"全原子"**——但注意，它的全原子是"残基 frame + 侧链扭转角"的可重建全原子，不是 AF3 式逐原子坐标扩散（详见 §3.1）；
3. **条件接口**——通过固定部分链、掩码部分链实现链级条件生成，而不是表位级条件。

本次学习目标：

- 搞清楚"全原子"在 APM 里到底指什么，避免与 AF3 / RFAA / ATOMICA 的原子级表征混为一谈；
- 把三轴（表征粒度 × 生成范式 × 条件接口）填实，而不是照抄对比表；
- 判断它对**抗体 / VNAR 设计**这条线的实际可迁移性——尤其是"零样本就能生成结合物"这个卖点能不能用到纳米抗体上。

**材料边界**：本次依据 arXiv 2504.13075v3 全文（PDF 转文本，落在 work 目录 `apm_2504.13075.txt`）；代码仓库 `github.com/bytedance/apm` 只核实了存在性与 LICENSE（Apache-2.0），**未跑通任何示例**；权重/数据的具体许可页未打开，相关条目标注【未核实】。

## 2. 核心概念

| 术语 | 含义 |
| ---- | ---- |
| Seq&BB Module | 主干生成模块（52M），流匹配同时生成序列与主链结构，是 APM 的基础模型 |
| Sidechain Module | 侧链补全模块（22M），给定序列与主链后预测 χ1–χ4；只在 t ≥ 0.8 后激活 |
| Refine Module | 全原子精修模块（54M），在 Seq&BB 输出上做残基类型与几何的联合松弛，初始化为"零改动"以免负优化 |
| SE(3) flow matching | 在主链残基 frame（旋转 + 平移）上定义连续流，从噪声 frame 运输到数据 frame |
| Discrete Flow Matching | 序列侧的离散流匹配：在 20 类氨基酸单纯形上定义概率路径，训练目标退化为对 x̂₁ 的交叉熵 |
| χ1–χ4 | 每个残基的四个侧链扭转角；配合主链 frame 可重建除氢以外的重原子 |
| 解耦加噪 | 序列时间步 t_S 与结构时间步 t_T 独立采样，不强制对齐，以保留序列-结构依赖 |
| chain-by-chain generation | 逐链生成：已生成链作为无噪条件下文，继续生成下一条链 |
| RAbD | 抗体 CDR 设计基准（Adolf-Bryfogle et al., 2018） |
| LNR / PepBench | 肽-受体结合能评测集 / 肽设计训练验证集 |
| SFT vs zero-shot | APM 在 SAbDab 上监督微调后的版本 / 完全未见抗体数据的原始版本 |

## 3. 原理与推导

### 3.1 表征：为什么"全原子"其实是残基级 + 侧链隐变量

论文第 3.1 节明确给出了取舍：不同氨基酸的原子种类、数量、拓扑都不同，当序列本身还没确定时，直接建模原子坐标很麻烦。作者对比了三条路：

- 集成式（Chu et al., 2024b）：同时建模所有氨基酸类型的侧链坐标；
- 虚拟原子（Martinkus et al., 2024）：把不可旋转原子合并；
- 直接全原子坐标（AF3 式，Qu et al., 2024）。

APM 选的是第四条：**残基级信息 + 侧链构象参数化**。一个残基被表示为

```text
(氨基酸类型 token, 主链 frame ∈ SE(3), 侧链扭转角 χ = (χ1, χ2, χ3, χ4))
```

配合固定的理想键长键角表即可重建重原子坐标，但**模型本身从不输出逐原子坐标，也不建模氢原子**。所以：

- 说它"全原子"是**表示能力**意义上的（能给出侧链构象、能算能量、能看原子级界面），【核实：论文 3.1 节原文】
- 说它"原子级扩散"是**错的**——它的扩散/流匹配发生在残基 frame 与扭转角上，不在原子坐标上。

这一点直接决定三轴里的 granularity 填"残基级 + 侧链隐变量"，而不是"全原子坐标"。

### 3.2 三模块架构与分阶段激活

整体流程是"由粗到细"的三段式（Figure 2）：

1. **Seq&BB**：从纯噪声出发，流匹配联合生成序列与主链；
2. **Sidechain**：在 t ≥ T（T = 0.8）后介入，给定当前序列与主链预测侧链扭转角；
3. **Refine**：同样在 t ≥ 0.8 后介入，用全原子信息联合修正残基类型与几何，缓解主链冲突。

为什么不让一个模型直接出全原子？论文给了两条理由【核实：3.2.1 节】：

- 侧链预测需要**真实**序列与结构才能拿到准确标签，而流匹配模型输入的是加噪版本；
- 若用流匹配生成侧链，就得提供加噪的 χ_t，而 χ_t 本身携带氨基酸类型信息，会造成**序列信息泄漏**（表现为训练中氨基酸类型 loss 收敛过快）。

工程细节【代码／配置核实：附录 B 超参段】：残基级/对级维度在 Seq&BB 与 Refine 中为 384/192，在 Sidechain 中为 256/128；Refine 初始化为恒等映射。

### 3.3 训练目标：把序列流与结构流拆开

Seq&BB 的损失是两项之和：

```text
L_flow = L_discrete + L_SE(3)
L_discrete = CE( p(Ŝ1 | S_tS, T_tT), S1 )
L_SE(3)    = MSE( T̂1, T1 )        # 在 frame 上做去噪回归
```

三个任务共用同一个网络，只是条件不同【核实：3.3.1 节】：

| 任务 | 条件形式 |
| ---- | ---- |
| 无条件生成 | p(S1, T1 \| S_tS, T_tT, t_S, t_T) |
| 逆折叠 | p(S1 \| S_tS, T1, t_S) |
| 折叠 | p(T1 \| S1, T_tT, t_T) |

多链场景下每个任务都有条件版本：把部分链设为无噪状态，作为上下文。

两个针对"序列-结构依赖被破坏"的设计【核实：Introduction + 3.3】：

- **解耦加噪**：t_S 与 t_T 独立采样，避免两模态同时被拉到同一噪声水平而切断依赖；
- **50% 概率切换任务**：训练时以一半概率做折叠或逆折叠，强迫模型从两个方向都学依赖。

此外还加了**一致性损失（consistency loss）**：对相邻时间步的两次预测做 KL 约束，让更接近数据端的预测充当教师【核实：附录 B.1】。这不是 IgGM 那种"consistency 蒸馏加速采样"的用法，而是训练期正则。

训练分两阶段【核实：3.3 节 + Figure 3】：Phase I 分开训 Seq&BB 与 Sidechain；Phase II 三模块迭代联合训练，总损失为 `L = E[L_Seq&BB + L_Packing + L_Refine]`。

### 3.4 三轴判定

| 轴 | 取值 | 判定依据 |
| ---- | ---- | ---- |
| 表征粒度 | 残基级 + 侧链隐变量 | 残基 token + 主链 frame + χ1–χ4；可重建重原子，无氢、无逐原子坐标【核实：3.1】 |
| 生成范式 | 流匹配（SE(3) 结构流 + 离散序列流） | `L = L_discrete + L_SE(3)`；序列用 Discrete Flow Matching【核实：3.3、附录 A】 |
| 条件接口 | 链级条件：受体链 / 抗原链 / 固定链 / 待生成链 | 逐链生成；抗体任务中明确"不指定结合位点"【核实：D.4】 |

**填不出的部分及原因**：表位残基级条件、MSA、模板、CFG 引导强度——这四项论文都没有；且不是"没写清"，是**设计上就没有**（抗体设计段落原文："we do not specify binding sites"）。所以矩阵里若把 APM 写成"抗原→CDR-H3"是对的，但若暗示它做表位特异设计则是误读。

### 3.5 在全原子谱系里的位置

用专题 01 §6.1 的三轴看，APM 落在：

```text
表征：残基级 + 侧链隐变量（介于"主链显式+侧链隐变量"与"全原子坐标"之间，偏前者）
生成：流匹配（连续结构 + 离散序列）——与 La-Proteina 同族，但序列是显式离散流而非 VAE 解码
条件：链级（结构条件），不是表位级、不是功能级
```

与相邻工作的差别：

- vs **AF3 / Boltz 系**：那些是结构预测（给定序列与 MSA 去噪），APM 是**生成**（序列也生成），且不用 MSA；
- vs **La-Proteina**：同样用隐变量处理侧链，但 APM 的侧链是显式扭转角 + 独立 Sidechain 模块，并在采样后段加 Refine；
- vs **IgGM**：IgGM 是抗体专用（抗原 + 表位 + CDR 掩码），APM 是通用复合物模型（抗体只靠 SFT 适配，且无表位条件）。

## 4. 训练数据构成与切分

### 数据源与规模

**单链（合计 187,494）**【核实：4.1 节】：

| 来源 | 条数 | 过滤 |
| ---- | ---- | ---- |
| PDB | 18,684 | 沿用 MultiFlow 的处理流程 |
| Swiss-Prot | 140,769 | pLDDT > 85 |
| AFDB | 28,041 | pLDDT > 95（更严） |

注意 Swiss-Prot / AFDB 是**预测结构**而非实验结构，pLDDT 阈值就是质量闸门；这也意味着训练集里混入了大量模型 hallucination 风险。

**多链（11,620）**【核实：4.1 节】：PDB Biological Assemblies。剔除规则三条：

1. PDB ID 出现在 **SAbDab** 中 → 直接丢（为抗体任务留出干净测试面）；
2. 含任一条 < 30 aa 的链（视为肽）→ 整样本丢，因此损失了 12,163 个样本；
3. 长度 > 2048 或无 cluster ID → 丢。

第 2 条值得单独记：作者承认"只删肽段不合理"（肽常常稳定复合物），所以选择整样本剔除。这直接导致**肽-受体复合物几乎不进预训练**，后续肽设计只能靠 PepBench 微调。

### 清洗、切分与泄漏控制

- **裁剪**：多链样本超过 384 残基做随机 crop 防 OOM【核实：4.1】；
- **抗体 SFT 切分**【核实：D.4】：SAbDab（IMGT 方案）→ 只保留轻重链齐全、抗原为蛋白的复合物 → 按 CDR-L3/CDR-H3 去重 → 以 CDR-H3 做 MMseqs2 40% 聚类 → **剔除含 RAbD 成员的簇** → 剩余按 9:1 分训练/验证（1,786 / 193），测试用 RAbD 中 55 个合规复合物；
- **肽任务**【核实：D.5】：PepBench 训练/验证，LNR 测试；丢掉含非标准氨基酸的样本；
- **预训练 vs 下游的隔离**：预训练阶段已排除 SAbDab 全部 PDB ID，所以"零样本抗体生成"确实是没见过抗体的——这个设计值得肯定。

### 覆盖与偏置

- **抗体覆盖极低**：预训练 0 抗体（按 PDB ID 排除），SFT 才引入 1,786 个复合物；且 SFT 集只保留"轻重链齐全 + 蛋白抗原"，**单域重链 / VNAR 不在训练分布内**；
- **肽覆盖被人为清空**：<30 aa 链整样本剔除，等于把肽复合物从预训练里拿掉；
- **构象偏置**：AFDB/Swiss-Prot 是单构象预测，多链只有 PDB 生物组装（晶体偏置）；
- **物种/长度偏置**：论文未给物种、长度分布统计【未核实：4.1 节及附录均无此表】。

## 6. 实践与应用

**适用场景**

- 多链复合物从头生成（给定受体链，生成结合链）；
- 多链 folding / inverse folding（统一框架，一套权重切任务）；
- 抗体 CDR-H3 设计（需 SFT）；
- 肽设计（需 PepBench 微调）。

**不适用 / 需谨慎**

- 需要**表位特异**的结合物设计：APM 无表位条件，只在链级做条件；
- 需要严格物理能量优化的场景：侧链只有扭转角，Refine 不是力场；
- 长体系（>384 残基需裁剪训练；推理长度上限论文未明示）【未核实】。

**关键参数（论文口径）**

| 参数 | 值 | 说明 |
| ---- | ---- | ---- |
| Sidechain/Refine 激活阈值 T | 0.8 | 过早介入会拿到低质量侧链 |
| 抗体候选数 | 64 / 抗原 | RAbD 评测设置 |
| 肽候选数 | 40 / 样本 | LNR 评测设置 |
| 肽长度 | 预设为真值长度 | 非自由生成长度 |
| 训练裁剪 | 384 残基 | 超长多链随机 crop |

**复现提示**：本次未实际跑代码，以下为读代码前的注意事项——(1) 权重许可未核实，商用前必须确认；(2) 折叠/逆折叠/生成是同一模型不同条件，切换靠输入掩码而非不同 checkpoint；(3) 抗体与肽都需要下游 SFT，直接用预训练权重做抗体设计会得到"像普通蛋白的结合物"（作者自己的解释）。

## 7. 疑问与讨论

- **Q**：APM 到底算不算"全原子模型"？
  - **A**：算"可重建全原子"，不算"原子坐标生成"。它的采样变量是残基 frame + 4 个扭转角，重原子由内坐标重建，氢原子不建模。与 AF3 / RFAA / ATOMICA 的原子级表征不是一回事。写综述时应标注为"残基级 + 侧链隐变量"。

- **Q**：为什么零样本抗体 ΔG 更好，AAR 却大幅下降？
  - **A**：作者解释是预训练里排除了 SAbDab，模型按"普通蛋白如何结合另一条链"来生成，所以能给结合面但不像天然 CDR-H3；且不指定结合位点，可能随机结合抗原或轻链。这其实说明**"会结合"与"像抗体"是两个能力**，SFT 主要买的是后者。

- **Q**：为什么抗体/肽都不在预训练里，还能做这两个下游？
  - **A**：预训练学的是"链间原子级相互作用"这个通用先验，抗体与肽只是把它特化。代价是必须 SFT，且 SFT 数据规模小（抗体 1,786），泛化到 VNAR/单域重链没有证据。

- **Q**：与 IgGM 最本质的区别？
  - **A**：IgGM 是抗体专用 + 表位条件 + CDR 掩码 + 主链 Cα/frame 扩散；APM 是通用复合物 + 链级条件 + 全原子可重建 + 流匹配。做表位特异设计选 IgGM，做复合物通用生成选 APM。

- **Q**：Table 6 与 Table 10 的抗体能量为什么差两个数量级？
  - **A**：Table 6 走常规流程（主链+侧链都 relax，基线需要额外 sidechain packing），Table 10 固定主链只 relax 侧链，专为消除 packing 方法差异。两套数字不能互相引用。对比表把"能量领先"写成无条件结论，属于口径丢失，已记入待订正清单。

## 8. 学习心得

- APM 最值得学的是**"表示层做取舍"**：不追逐原子坐标，而是用 frame + 扭转角在"算得动"和"有原子信息"之间取平衡。这比无脑堆原子 token 更工程化。
- **三模块分阶段激活**是个很实用的设计模式：生成早期只管主链，后 20% 时间步才让侧链/精修介入，既省算力又避免早期噪声污染。
- **数据侧的"故意留白"**值得记：为抗体任务把 SAbDab 从预训练里清干净，才让零样本结果有说服力。反过来，把 <30 aa 链整样本删掉，也让肽任务失去了预训练先验——这是同一套清洗规则的两面。
- 读这类"全原子"标题的论文，第一件事应该是翻到 representation 小节，而不是看 abstract。
