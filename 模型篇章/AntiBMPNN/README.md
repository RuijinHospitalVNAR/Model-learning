## 1. 学习背景与目标

AntiBMPNN 是抗体专用的**逆折叠**模型：输入抗体主链，输出每个位置的氨基酸概率。它不做结构生成、不用抗原、不建模侧链，因此严格说不在“全原子生成”谱系的主干上；它被列进矩阵，是因为它是“有 3D 上下文但只输出序列”这一格的典型代表，也是判断“全原子生成模型到底比逆折叠多给了什么”的对照物。

本次目标：

1. 定名，厘清 AntiBMPNN / AbMPNN / ProteinMPNN / LigandMPNN / “BMPNN” 的关系；
2. 给它在三轴里的诚实坐标（不把“主链图”写成“全原子”）；
3. 判断它对 VNAR 项目的实际可用边界。

## 2. 核心概念

| 术语 | 含义 |
| ---- | ---- |
| 逆折叠（inverse folding） | 固定主链、预测序列；与“给定序列预测结构”方向相反 |
| MPNN | Message Passing Neural Network，在残基图上做消息传递 |
| 虚拟 Cβ | 由 N/Cα/C 几何构造的虚拟侧链起点，ProteinMPNN 的标准做法 |
| backbone noise | 训练时对输入主链加扰动，提升对不完美结构的鲁棒性 |
| 频率打分 | 对同一主链采样大量序列，按残基出现频率 + 理化描述符聚类排序 |
| AbMPNN | 2023 年的抗体逆折叠模型（arXiv 2310.19513），**与 AntiBMPNN 不是同一个工作** |
| BMPNN | 未检索到以此命名的独立模型；在本行语境里只是 “backbone/message-passing MPNN” 的简写【未核实：Google/arXiv/PMC 检索无独立条目】 |

## 3. 原理与推导

### 3.1 定名与谱系关系（本笔记最重要的一节）

| 名称 | 身份 | 与 AntiBMPNN 的关系 | 证据 |
| ---- | ---- | ---- | ---- |
| ProteinMPNN | 通用蛋白逆折叠，主链图 + 自回归/非自回归解码 | AntiBMPNN 的**架构与代码基座**；AntiBMPNN 是其在抗体数据上的重训/微调 | 【核实：原文“built upon structured transformers… MPNN as aggregation” + 与 ProteinMPNN 的对照实验】 |
| AbMPNN | 抗体逆折叠，ProteinMPNN 架构，在实验/预测抗体结构上微调 | **竞争基线**，不是前身；AntiBMPNN 在 CDR 恢复率表中把 AbMPNN 列为对比模型 | 【核实：原文 §2.2 与 Figure 1e】 |
| LigandMPNN | ProteinMPNN 的配体/非蛋白原子扩展版 | 与 AntiBMPNN 无直接继承；AntiBMPNN 不建模配体、不建模侧链 | 【推断：原文未提 LigandMPNN，且方法无配体节点】 |
| BMPNN | 无独立模型 | 名称中的 “BMPNN” 是对 MPNN 的抗体化命名，不应作为第三个模型单列 | 【未核实：检索无果】 |

> **结论**：CSV 行名 “AntiBMPNN / AbMPNN” 且同时挂 Adv Sci DOI 与 arXiv 2310.19513，是把两篇不同论文合并了。正确写法应是两行：AntiBMPNN（Adv Sci 2025）与 AbMPNN（arXiv 2310.19513）。详见 `work/待订正清单.md`。

### 3.2 表征：主链图，不是全原子

- 节点是原子（N、Cα、C、O，加虚拟 Cβ），边编码键/距离；**没有侧链原子、没有抗原链、没有配体**。【核实：原文 Graph Representation 段】
- 输出是每个残基的 20 类分布；结构始终是输入，不被生成。
- 因此它在“表征粒度五档”里是 **残基级/主链级**，不是全原子坐标，也不是侧链隐变量。

### 3.3 训练目标与推理

- 目标函数：逐残基交叉熵（可加权、可掩码），本质是**判别式**训练；没有噪声预测、没有去噪轨迹。【核实：原文方法段】
- 训练时对主链加 Gaussian noise（0–1 范围扫描），noise=0 时验证准确率最高（0.901），noise 增大后单调下降。【核实：Figure 1b/c 说明】
- 推理：给定主链，按温度 T 采样；T 越低越接近天然序列，T 越高多样性越大。【核实】

### 3.4 频率打分 + AF3 复筛（AntiBMPNN 的“第二半”）

AntiBMPNN 不只是一个网络，而是一条流水线：

1. 对目标主链采样 **32,768** 条序列；
2. 按残基频率聚类（示例中 147 簇），叠加 volume/hydrophilicity/charge 等理化描述符排序；
3. 用 AF3 单体模式取最高 pLDDT、复合物模式取最高 ranking_score；
4. 选 1–2 条做湿实验。【核实：原文 §2.4 与 Figure 2】

这一步是“用生成模型的采样频率当先验”，不是学习出来的打分器；它的偏差会直接继承训练集（SAbDab）的残基偏好。【推断】

### 3.5 三轴定位

| 轴 | 取值 | 说明 |
| ---- | ---- | ---- |
| 表征粒度 | 残基级主链图 | N/Cα/C/O + 虚拟 Cβ；无侧链、无抗原 |
| 生成范式 | 非生成式 | 逆折叠分类；无扩散/流匹配/自回归 |
| 条件接口 | 主链坐标 | 无抗原、无表位、无 MSA；条件强度最弱的一档 |

## 4. 训练数据构成与切分

- **数据源与规模**：SAbDab，沉积日期 **≤2024-01-22**，分辨率 **≤5 Å**，共 **8,078** 个抗体结构。【核实：Training Datasets 段】
- **清洗与去重**：配对抗体拆成独立 H、L 单域；去精确序列重复与冗余结构；按 **CDR 30% 序列一致性**聚类；含多拷贝抗体的结构不入训练集，训练时随机采样。【核实】
- **切分与泄漏控制**：时间切分——测试集为 **2024-01-22 之后**沉积的 SAbDab 结构，同一清洗协议，最终 **120** 个（40 H+L、40 H、40 L）。【核实】
- **覆盖与偏置**：
  - 单域化后 H/L 各自成样本，等于把“配对信息”丢掉了；模型学不到轻重链协同。【推断，依据数据处理】
  - 抗体为主，**纳米抗体/VNAR 占比极低**；论文的湿实验用的是人源化骆驼 VHH（huJ3），不是鲨源 VNAR。【核实：原文 §2.5】
  - 无抗原结构进入训练，因此模型对“界面互补”没有直接监督；论文也把“引入抗原结构”列为 future work。【核实：讨论段】
- **可获取性与许可**：论文称脚本上传至 AntiBMPNN 的 GitHub 仓库，但正文未给出可访问 URL；本次未找到官方仓库。【未核实：查过原文 Code Availability/数据可用性段与 GitHub 搜索】
- 训练性能评估用了 **6,578** 个结构（8,078 经拆分/去重后的训练子集）。【核实：§2.1】

## 6. 实践与应用

- **适用场景**：已有抗体/VHH 实验结构或高质量预测结构，做 CDR 局部重设计、单点/少点突变筛选、NGS 库的序列先验过滤。
- **不适用**：de novo 抗体生成、抗原特异性设计、需要侧链/结合能判断的任务、没有主链的场景。
- **关键参数**：
  - backbone noise：0 最准；0.1–0.3 增加多样性但掉恢复率；用于设计时可在 0.02–0.1 间折中。【核实：Figure 1b】
  - 采样温度：0.1 附近偏保守；>0.5 多样性上升、恢复率下降。【核实】
  - 打分：必须用频率 + 理化 + AF3 复筛组合，单看模型概率会过拟合训练集偏好。
- **对 VNAR 的具体用法**：把 VNAR 的 CDR3（甚至只 CDR3 的若干位点）掩码，主链用实验结构或 AF3 预测，做 10³–10⁴ 采样，再按频率/理化/AF3 排序。不要指望它改 CDR1/框架——VNAR 的 CDR1 与框架二硫键不在它的训练分布里。【推断 + 数据核查】

## 7. 疑问与讨论

- **Q**：AntiBMPNN 是“全原子模型”吗？
  - **A**：不是。它只用主链原子 + 虚拟 Cβ，输出序列；把它放进全原子矩阵只能占“序列设计/逆折叠”对照格。

- **Q**：它和 AbMPNN 谁更强？
  - **A**：在论文自己的 120 结构测试集上，AntiBMPNN 的 CDR 恢复率在 4/6 个 loop 最高（CDRH1 0.7358、CDRH3 0.5800、CDRL1 0.8129、CDRL2 0.8259），但 CDRH2/CDRL3 输给 AntiFold。两者是同一架构路线的不同数据/训练方案，不构成“继承”关系。【核实：Figure 1e】

- **Q**：为什么它不用抗原也能做“抗体设计”？
  - **A**：它做的是“序列可设计性/可折叠性”，不是“结合特异性”。抗原只在 AF3 复筛阶段以复合物打分的形式出现，不进入模型。【核实：方法 + §2.4】

- **Q**：CDR-H3 为什么这么难？
  - **A**：H3 长度/构象多样性最高、训练样本最少；论文自己也报告 H3 恢复率最低（0.4314）。这与 IgGM 的 36% 是同一问题的两种度量，不可直接比较。【推断】

## 8. 学习心得

- AntiBMPNN 提醒我：**“用了 3D 结构”不等于“全原子”**。它的信息瓶颈在主链图，侧链与抗原本征缺失，因此它的高分主要来自“抗体序列统计先验 + 主链几何”，不是界面物理。
- 它的流水线设计（采样→频率聚类→AF3 复筛）比网络本身更值得借鉴；这套“生成候选 + 结构复筛”的思路可以直接搬到 VNAR。
- 对 VNAR，最现实的定位是“CDR3 局部优化器”，而不是“VNAR 生成器”。
