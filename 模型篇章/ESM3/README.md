## 1. 学习背景与目标

ESM3 是 EvolutionaryScale 的多模态蛋白语言模型（Science 2025，DOI 10.1126/science.ads0018；bioRxiv 2024.07.01.600583）。它在本文库里的位置比较特殊：**它不在"全原子生成"那条扩散/流匹配主线上，而是把结构离散化成 token，用语言模型的方式做生成**。把它放进矩阵，价值在于提供一条对照路线——

> 别人用 SE(3) 扩散/流匹配在连续坐标上生成，ESM3 用 VQ-VAE 把结构压成 4096 个码本 token，然后统一用"掩码—预测"来生成。

本次学习目标：

1. 搞清楚"三个 track"到底是什么、怎么融合；
2. 把 VQ-VAE 结构分词器的输入输出、码本规模、重建精度写实；
3. 理清 ESM3 与 ESM2 / ESMFold 的继承与差别；
4. 把数据规模与开放程度写清楚——这两项直接决定它能不能被当作可复现基线。

**材料边界**：依据 bioRxiv 全文（PDF 转文本，work 目录 `esm3_biorxiv.txt`），Science 正式版未单独核对；权重页与 Hugging Face 模型卡的许可文本**两次抓取均返回空**，因此许可部分标注【未核实】并写明查过哪里。

## 2. 核心概念

| 术语 | 含义 |
| ---- | ---- |
| track（轨） | 同一残基位置上的一种模态通道；输入输出都是离散 token，在模型内融合进同一隐空间 |
| 生成式掩码语言模型 | 训练时对任意比例、任意子集的位置加 mask，监督被 mask 的 token；掩码率覆盖 0–1 全区间，而非 BERT 式固定 15% |
| 迭代 unmask | 推理时从全掩码或部分掩码出发，按任意顺序逐批采样 token，直到全部解掩码 |
| VQ-VAE 结构分词器 | 把每个残基周围的局部主链几何编码成 1 个离散 token（码本 4096），再由 decoder 重建主链坐标 |
| 几何注意力（geometric attention） | 首层用主链原子坐标构造残基 frame，做 SE(3) 不变的全对全注意力；坐标只作输入，不作输出 |
| SS8 / SASA 轨 | 8 类二级结构 token 与 16 桶溶剂可及表面积 token，作为结构的粗粒度抽象 |
| 功能轨 | 功能关键词（每残基 8 个 LSH 量化 token，词表 255）+ InterPro 残基注释（1478 维多热） |
| chain-of-thought | 先出 SS8 → 再出结构 token → 最后出序列的分步提示流程 |
| esmGFP | 用 ESM3 7B 经 chain-of-thought 生成的荧光蛋白，与最近天然荧光蛋白 58% 同源 |
| ESM3-open | 1.4B 开放权重版本，论文写明"仅供学术研究使用" |

## 3. 原理与推导

### 3.1 统一表示：一切皆 token

ESM3 的核心主张写在摘要里：**不用 3D 扩散，也不用复杂几何架构，而是把三维结构编码成离散 token，让 all-to-all 的 Transformer 去建模**【核实：摘要 + 1 节】。

严格说不是"三个轨"，而是**七个输入轨**（附录 A.1.5.1）【核实】：

| 编号 | 轨 | 说明 |
| ---- | ---- | ---- |
| a | 序列 | 20 标准氨基酸 + 4 非标准（B/U/Z/O）+ BOS/EOS/mask/pad/unknown，共 29 token |
| b | 结构坐标 | 主链原子坐标，走几何注意力，不 embed |
| c | 结构 token | VQ-VAE 码本 4096 + 4 特殊 token |
| d | SS8 | 8 类二级结构 + unknown + mask，共 10 token |
| e | SASA | 连续值离散成 16 桶 + unknown + mask，共 18 token |
| f | 功能关键词 | 每残基 8 个 token，每个取自 255 词表（LSH 量化） |
| g | InterPro 残基注释 | 1478 维多热向量，最多 16 条 |

预训练时另有两个只在训练期使用的轨：per-residue pLDDT 与平均 pLDDT；98B 还在最后 30K 步启用 taxonomy 轨【核实：A.1.5.1】。

所以"sequence / structure / function 三轨"是**语义层面的归纳**，实现上是七轨。写综述时如果只写三轨，会漏掉 SS8/SASA 这两个中间抽象层——而它们恰恰是 chain-of-thought 的第一步。

### 3.2 生成式掩码目标

训练目标是标准的掩码交叉熵，但掩码率 m 从噪声调度里采样，覆盖全区间：

```text
L = −E_{x,m} [ (1/|m|) Σ_{i∈m} log p(x_i | x_{\m}) ]
```

与经典 MLM 的差别【核实：1 节】：

- 监督**所有可能的掩码率**，而不是固定 15%；
- 因此模型学到的是"给定任意模态的任意子集，预测其余部分"，即任意顺序生成；
- 高掩码率提升生成能力，低掩码率提升表征能力，作者用一条折中的噪声调度兼顾两者。

论文明确说这个目标"factorizes the probability distribution over all possible predictions of the next token given any combination of previous tokens"【核实】——这是它不引入扩散模型却仍能做生成的理论依据。

### 3.3 结构分词器：VQ-VAE 把主链压成 4096 个码

- **输入**：每个残基周围的局部主链几何（局部邻域，含相邻残基信息）；
- **表示**：每残基输出 1 个离散 token，码本大小 4096；
- **训练损失**：几何损失，监督成对距离、键向量与法向的相对朝向（不是逐坐标 MSE）；
- **解码**：两阶段训练——先训小 decoder 学结构，再冻结码本训更大 decoder 提升重建；
- **重建精度**：CAMEO 上 < 0.5 Å RMSD【论文自称：Fig. S3】。

一个容易忽略的点：结构 token 的局部邻域**包含邻近结构的信息**，所以单 token 不是只描述本残基。这也是为什么还需要几何注意力来补全局坐标信息（见 3.4）。

**关键限制**：分词器只覆盖主链。所谓"full atomic structure"在论文里指 decoder 重建出的主链/骨架结构，**不含侧链构象建模**。因此 ESM3 不能算全原子模型，三轴里只能填"离散 token"。

### 3.4 几何注意力：坐标只进不出

首层有一个 SE(3) 不变的全对全注意力（附录 A.1.6）【核实】：

- 每个残基由主链坐标定义一个 frame `T_i = (R_i, t_i) ∈ SE(3)`；
- 注意力在 frame 的相对距离与相对朝向上做推理；
- 计算原语与普通 attention 相同，所以可扩展；
- **坐标只作为输入**，输出永远是离散 token（结构 token、SS8、SASA 等）。

这样做的好处是：结构 token 负责"快学、语义压缩"，几何注意力负责"细粒度、部分结构条件下的局部几何"。二者互补。

### 3.5 三个尺度与 scaling

| 规模 | 层数 | 备注 |
| ---- | ---- | ---- |
| 1.4B | 48 | 对应开放的 esm3-open |
| 7B | 96 | esmGFP 由 7B 生成 |
| 98B | 216 | 仅 API；另有 taxonomy 轨 |

作者报告：加深比加宽收益更大，所以三个规模都偏深【核实：1 节 + A.1.5】。

### 3.6 与 ESM2 / ESMFold 的关系

| 维度 | ESM2 | ESMFold | ESM3 |
| ---- | ---- | ---- | ---- |
| 输入 | 序列 | 序列（单序列，无 MSA） | 序列 / 结构 / 功能任意组合 |
| 输出 | 序列表征 / 掩码 token | 3D 坐标 | 各轨 token（结构 token 再解码成坐标） |
| 目标 | BERT 式掩码 LM | LM 表征 + folding trunk | 生成式掩码 LM（全掩码率） |
| 与 ESM3 关系 | ESM3 的"前身模态"，但架构与目标都换了 | ESM3 在 CAMEO 单序列结构预测上超过它（LDDT 0.895 vs 0.865）【核实：1 节】 | — |

注意：ESM3 **没有** folding trunk，也不做 MSA。它的结构预测是"生成结构 token → decoder 重建"，这与 ESMFold 的端到端坐标回归是两条路。0.895 vs 0.865 的比较是**单序列**设定，不能外推成"ESM3 全面优于 ESMFold"。

### 3.7 三轴判定

| 轴 | 取值 | 判定依据 |
| ---- | ---- | ---- |
| 表征粒度 | 离散 token（序列 29 类；结构 4096 码本；仅主链） | 附录 A.1.3、A.1.7【核实】 |
| 生成范式 | 掩码语言模型（生成式掩码 + 迭代 unmask） | 摘要与 1 节明确"not diffusion"【核实】 |
| 条件接口 | 任意轨组合提示（序列/结构/功能/SS8/SASA/坐标） | 七轨可任意 mask【核实】 |

**填不出的部分**：表位条件、链级配对条件、CFG 引导系数——论文未提供，也没有对应的条件轨。ESM3 面向单链蛋白，复合物/抗体配对链不是其设计目标【推断：全文未出现多链训练或界面条件的描述】。

### 3.8 chain-of-thought 与 esmGFP

生成流程不是一次解掩码，而是分步【核实：Fig. 4 + 附录】：

```text
提示（部分序列 + 部分结构）
  → 先解掩码 SS8（二级结构骨架）
  → 再解掩码结构 token（主链几何）
  → 最后解掩码序列（氨基酸）
```

esmGFP 的关键数字【核实：正文 + Fig. 4】：

- 与 *Aequorea victoria* GFP 36% 序列一致；
- 与**最近天然荧光蛋白** 58% 一致，相当于 96 个突变；
- 按序列同一性换算的进化距离 > 5 亿年——这是**估算口径**，不是实验测年【论文自称/推断】。

## 4. 训练数据构成与切分

### 数据源与规模

【核实：1 节 + A.2.1】

| 项 | 数量 |
| ---- | ---- |
| 天然蛋白序列 | 2.78B |
| 补入逆折叠合成序列后的序列总数 | 3.15B |
| 结构（实验 + 预测） | 236M |
| 有功能注释的蛋白 | 539M |
| unique tokens | 771B |
| 最大模型训练算力 | 1.07e24 FLOPs |

构成逻辑：

1. 从序列库与结构库收 2.78B 天然蛋白；
2. 实验结构远少于序列，所以**大量使用预测结构**（ESMFold/AlphaFold 类）；
3. 功能关键词用 HMM 库（Pfam 系）注释；
4. 对**所有结构**（含预测结构）用逆折叠模型生成合成序列，把数据从 2.78B 扩到 3.15B。

### 清洗、切分与泄漏控制

- 论文正文给出了规模，但**去重阈值、聚类方式、时间切点、测试集隔离细节都在附录 A.2.1**，本次未逐条核实【未核实：仅读正文与部分附录，未核对 A.2.1 全文】；
- 评测用了 CAMEO（时间切分性质），但训练切点日期未在正文给出【未核实】；
- 功能注释来自 HMM 库自动注释，存在**注释错误传播**风险，论文未量化【未核实】。

### 覆盖与偏置

- **结构覆盖偏斜**：236M 结构中绝大多数是预测结构，实验结构占比很小；预测结构的系统性误差会进入训练；
- **功能注释稀疏**：539M / 3.15B ≈ 17% 的序列有功能注释，功能轨大部分位置是 mask；
- **单链偏置**：训练语料以单链为主，多链复合物与抗体配对链不是重点【推断】；
- **物种偏置**：未给物种分布表【未核实】。

## 6. 实践与应用

**适用场景**

- 蛋白序列/结构/功能的条件生成（motif scaffolding、功能关键词引导）；
- 表征学习（嵌入用于下游分类、突变效应）；
- 单序列结构预测（无需 MSA，适合 orphan 序列）；
- 远源蛋白设计探索（esmGFP 式 chain-of-thought）。

**不适用 / 需谨慎**

- 侧链/全原子精度任务：结构轨只到主链；
- 抗体/纳米抗体配对链设计：无链级条件接口；
- 复合物界面设计：非设计目标；
- 商用：开放权重限学术用途，商用需另谈 API/许可。

**使用要点**

1. 提示构造是核心技能：同一个目标可以用"序列提示 / 结构 token 提示 / 坐标提示 / 功能关键词提示"四种方式表达，效果不同；
2. chain-of-thought 的顺序（SS8 → 结构 → 序列）不是可选项，乱序会显著掉点【论文自称】；
3. 高掩码率利于生成、低掩码率利于表征，做嵌入时不要用生成模式；
4. 结构输出必须过 decoder 才是坐标，中间产物是 token。

**未实测**：本次未安装 `esm` 包、未调用 API，以上为读论文后的使用判断。

## 7. 疑问与讨论

- **Q**：ESM3 为什么不用扩散？
  - **A**：作者明确把"不做 3D 扩散"当作卖点：离散 token 的 all-to-all 建模更容易扩展，且同一套目标天然支持任意模态组合提示。代价是结构精度受分词器上限约束（<0.5 Å 重建误差），且无法直接建模侧链。

- **Q**：ESM3 算不算"全原子模型"？
  - **A**：不算。结构轨是主链几何的离散编码，decoder 重建的是骨架；论文里 "full atomic structure" 指的是相对 token 而言的坐标重建，不包括侧链构象采样。矩阵里应归"离散 token"格。

- **Q**：0.895 vs 0.865 是不是说明 ESM3 结构预测全面超过 ESMFold？
  - **A**：不能。这是 CAMEO 单序列 LDDT 一个指标，ESMFold 的优势场景是带 MSA/模板的常规预测；且 ESM3 的 98B 不可本地复现。

- **Q**：三个 track 的说法准确吗？
  - **A**：语义上准确，实现上是七轨（序列、坐标、结构 token、SS8、SASA、功能关键词、InterPro）。只写三轨会漏掉 SS8/SASA 这两个 chain-of-thought 的关键中间层。

- **Q**：ESM3 能做抗体设计吗？
  - **A**：没有证据。训练以单链为主，无配对链条件、无表位条件、无 CDR 掩码机制。它最多能做"给定框架序列做 CDR 序列补全"这种粗糙用法，与 IgGM/diffAb 这类专用模型不在一个量级。

## 8. 学习心得

- ESM3 最大的启发是**"换表示而不是换架构"**：把结构压成 token 后，扩散模型里的等变网络、噪声调度、采样器全都不需要了，剩下的就是成熟的 Transformer 栈。这是一个非常"工程实用主义"的路线。
- 但这条路线的天花板也很清楚：**分词器决定上限**。4096 个码本、只编主链，就意味着侧链与精细几何永远拿不回来。
- 数据侧的"用预测结构 + 逆折叠合成序列"把 2.78B 撑到 3.15B，是典型的"用模型造数据"闭环，值得与其他自蒸馏工作对照看。
- 开放程度是硬约束：主结论在 7B/98B，开放的是 1.4B，**"开源可复现"这句话在这里要打折**。
