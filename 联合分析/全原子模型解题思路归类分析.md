## 1. 分析目的

AlphaFold3、Mol-1 以及 Proteina、OpenDDE、AnewOmni、ATOMICA 等模型都以 diffusion 深度参与、面向**全原子（all-atom）**表示。但"让模型直接训练/生成每个原子的 x,y,z 坐标"非常困难，各模型给出了不同的解题思路。本文将这些思路归类、逐一分析，并给出综述写作的章节建议。

## 2. 共同难题：为什么"直接全原子坐标训练"难

1. **维度灾难**：每个原子 3 个坐标，一个复合物动辄数千至数十万原子，输出空间维度爆炸、训练数据相对稀疏；
2. **原子数可变**：不同残基/分子所含原子数不同，难以直接组织成规则张量；
3. **物理约束复杂**：键长、键角、手性、空间碰撞（steric clash）等规则必须满足，直接回归极易产生非法结构；
4. **对称性负担**：分子可任意旋转平移，模型必须处理 SE(3) 等变性，否则浪费容量去"记住姿态"；
5. **长程相互作用**：界面与远程残基间存在复杂空间依赖；
6. **计算成本**：原子级注意力/消息传递的显存与算力开销随规模急剧增长（Mol-1 实测显存随 token 数接近二次方增长）。

## 3. 归类框架总览

按**表示层策略**（如何绕开"一次性直接回归全部原子坐标"）可分为四大路线：

| 路线 | 代表模型 | 核心策略 | 一句话概括 |
| ---- | -------- | -------- | ---------- |
| ① 全原子直出 | AlphaFold3、Protenix→Mol-1 | 扩散模型在**原始坐标空间**逐步去噪，主干网络提供条件表示 | "不压缩不离散，让去噪慢慢来" |
| ② 连续隐空间压缩 | 2026 年 `rfd4-proteina` 模型、AnewOmni | 把（部分）原子压缩为**连续 latent**，在隐空间做流匹配/扩散，再解码回坐标 | "先压缩再生成" |
| ③ 离散结构 Token 化 | **无已核实成员**（原记 OpenDDE，2026-11-06 订正至路线 ①，见 §4.3） | 把主链/侧链拆为**离散 Token 图节点**，图网络推理后由扩散映射回坐标 | "把分子当语言来推理" |
| ④ 分层等变表征 | ATOMICA | **SE(3) 等变 GNN** 分层几何图 + 自监督去噪/掩码预测（表征为主） | "先把几何看懂，再谈生成" |

## 4. 各路线详解

### 路线 ①：全原子直出（AF3 / Protenix / Mol-1 / OpenDDE）

**核心思想**：不做隐空间压缩、不做离散化，让扩散模型直接在原子坐标上加噪–去噪；几何推理的重担交给主干（MSA module → Pairformer 的 token/pair 表示），扩散模块只负责"在条件引导下把坐标画准"。

**关键技术**：
- **AF3**：主干提取进化与序列上下文 → 扩散模块直接生成全部原子坐标；**不依赖物理力场损失**，靠数据规模 + 多样本采样 + 置信度网络排序来保证质量；
- **Mol-1**（依据官方仓库 README，已核实）：延续 Protenix/AF3 路线；蛋白 MSA 走 ColabFold MMseqs2 服务、模板走 HMMER 搜索 + kalign 对齐；每个 seed 扩散采样多个样本，按 `ranking_score` 排序输出（`sample_0` 即最优）；输出逐 token PAE 矩阵与 plddt 置信度；显存随 token 数接近二次方增长，靠多级 chunking（trunk/confidence/diffusion 各自可控）支撑 ~1500 tokens（95 GiB GPU），更大体系换 `--trimul_kernel torch` + expandable segments；
- **原子数可变的处理**：残基内原子 token 化/类型化坐标编码，使不规则原子集合同一化为规则序列。
- **OpenDDE**（2026，Aureka，arXiv:2607.03787）：AF3 家族的全原子共折叠预测器，相对 AF3 把 Pairformer 隐藏维从 128 提到 384，并在残基 token 之上加一层"结构 token"（按化学角色拆分的**连续隐节点** `s_u ∈ R^c`，不是离散 ID）用于界面推理；采样层仍是 **EDM 式连续坐标扩散**（`sigma_data=16.0`、`rho=7`、`s_max=160.0`、`gamma0=0.8`、`step_scale_eta=1.5`，发布默认 `N_step=200`），输出 atom37 + 配体／离子／核酸原子。核心改动是"先推理、再画坐标"，不是把结构离散化。【核实：论文 §2.1／§3.1、Appendix A.1；`opendde/config/model_base.py` L21–L64／L134／L169–L171；详见 [模型篇章/OpenDDE](../模型篇章/OpenDDE/README.md)】

**回应难题的方式**：扩散把"一步回归"拆成几百步小修正，缓解维度灾难与物理约束违背；多样本+置信度排名替代单点最优。OpenDDE 额外用 structural token 在坐标生成前做一轮显式界面推理，并以 shape-complementarity loss 监督界面贴合。

**代价**：推理成本高（多步去噪 × 多样本）；物理合理性靠数据学出而非硬约束，罕见化学仍可能翻车。OpenDDE 的 656 M 主干 + 默认 10 recycle × 200 step × 5 sample，推理成本显著高于 AF3 的默认口径。

### 路线 ②：连续隐空间压缩（AnewOmni / 2026 年 `rfd4-proteina` 模型）

**核心思想**：把难学的高维原子坐标压进低维连续隐空间，生成在隐空间完成，再解码回全原子。

**代表与不同取舍**：
- **AnewOmni**：**整体压缩**。按化学先验做分层"积木块（Building Blocks）"拆解——标准氨基酸/核苷酸直接保留；小分子与非天然氨基酸拆为数据库高频片段；罕见子结构兜底拆到单原子；再用**全原子 VAE** 把积木块几何压进连续共享隐空间（概率分布，非 VQ、无离散词表），在光滑隐空间做扩散后解码。跨模态泛化强（小分子↔多肽↔抗体），但原子级侧链精度弱于专用打包工具；物理约束偏隐式，需后验证。
- **2026 年 `rfd4-proteina.org` 模型**（旧笔记写作 "RFD4-Proteina"，与 2025 年的 Proteina 不是同一模型，即 `RosettaCommons/RFD4-Proteina` 仓库）：主链保留显式 Cα/C1′ 锚点坐标（接口 `bb_ca`），侧链走每残基 32 维 `local_latents`（**残基级**隐变量，非"侧链专属"）；推理期用 reward guided search——内部 recycling（120/180/300 次 trunk pass）+ 外部 checkpoint beam search，并以 AF3/OF3 oracle refold 作外部评分；微调阶段另加 Rosetta 能量损失（作用于**解码器**，对解码后坐标可微）。【核实：仓库代码与配置、技术报告、`concepts/search`、`concepts/metric-guidance`、`concepts/metrics`】
- **边界说明：Proteina（2025，arXiv 2503.00710）不属本路线。** 它是 Cα 单点流匹配主链生成（`x∈R^{3L}`，Atom37 只有 index 1 非零），没有侧链 latent、没有解码器、没有 Rosetta 能量项，也没有 beam search 或奖励搜索；可设计性评测用的是 ESMFold。旧笔记把上述四点记在它名下属于对象错置。回到 2026 年模型本身核验后：**"32 维"成立但为残基级隐变量；"0.82 Å PackBench"不成立**——全仓库与全文检索只命中 PLACER 的 AUROC 0.82，PackBench 真实口径是 MolProbity 1.70 vs LigandMPNN 1.99。【核实：arXiv 2503.00710；NVIDIA-BioNeMo/proteina；RFD4-Proteina 技术报告 §4.3 与 PackBench 段】

**回应难题的方式**：降维解决维度灾难与计算成本；解码器（物理监督 / VAE 数据分布）兜住物理合理性，2026 年 `rfd4-proteina` 模型另在推理期用 oracle refold + beam search 提升指标。

**代价**：压缩必有信息损失；latent 与物理约束的平衡需精细调优（2026 年 `rfd4-proteina` 模型）/依赖数据分布、隐式约束（AnewOmni）。

### 路线 ③：离散结构 Token 化（当前无已核实成员）

> **订正（2026-11-06）：原代表模型 OpenDDE 不属于本路线，已移至路线 ①。** 以下"核心思想／特点／代价"是原表述，保留作证伪记录，不再作为该路线的现状描述。

**原表述（保留作证伪记录）**

**核心思想**：把残基显式展开为 **Backbone Token 与 Side-chain Token** 等独立图节点，用图网络 + Pair-conditioned Attention / 三角更新让 Token 相互"协商"几何一致性，最后仍需底层扩散生成器映射回三维坐标，并做 steric clash 后处理。

**特点**：借鉴 AF 的 Pairformer，对天然复合物保留进化信号（MSA），面向**多分子共折叠预测**（蛋白–核酸–配体，如抗体–抗原）；结构 Token 化降低建模复杂度、便于多模态统一（结构/序列/配体 Token 同框架）。

**代价**：Token 离散化在"还原精确坐标"时丢失高频几何细节，必须靠扩散生成器+后处理找补；图网络训练复杂度高。

#### 订正说明：OpenDDE 属路线 ①，不属路线 ③

**证伪路径（怎么发现的）**：旧归类只写了"OpenDDE"、出处标注"待补" → 先钉到一手来源 arXiv:2607.03787（Aureka AI Research）→ 逐条核对论文 §2.1／§3.1／Appendix A.1 与仓库配置 → 三条证据全部指向"连续坐标采样"。

**三条否决证据**：

1. **无离散状态空间**：所谓 structural token 是连续隐节点 `s_u ∈ R^c`（由残基 token 状态加角色嵌入 `e_ρ(u)` 初始化），采样发生在 `R^{N_atom×3}` 连续坐标上，噪声为高斯而非 categorical。【核实：Appendix A.1、§3.1】
2. **无词表／码本／quantizer**：`opendde/model/` 与 `config/model_base.py` 中不存在 codebook、VQ、quantizer 类；`n_roles = 7` 是化学角色数，不是词表大小；`c_token = 384` 是 embedding 宽度。【代码／配置核实】
3. **采样超参与 AF3／EDM 逐项同构**：`sigma_data = 16.0`、`rho = 7`、`s_max = 160.0`、`gamma0 = 0.8`、`step_scale_eta = 1.5`、`N_step = 200`（发布默认）；论文 Table 1 也只有 Pairformer／structural refiner／diffusion 三块，**没有离散瓶颈层**。【核实：Table 1、`model_base.py` L54–L64】

**误判来源**：最可能是把缩写 "DDE" 展开成 "Discrete Diffusion Engine"；实际是 **Drug Discovery Engine**。"token" 一词描述的是连续 embedding 的分组单位，不是离散词表项——属术语债，不是技术矛盾。

**当前结论**：**路线 ③ 目前没有已核实成员。** 若要把它独立成一条路线，缺的不是再找一个"名字像离散"的模型，而是一个**"同一主干、只换采样空间"的对照实验**——即固定主干与数据，仅把采样层从连续坐标换成离散 token 化，并给出可比的 designability／DockQ 数字。没有这个对照，③ 只能算一个假设，不是一条已被证据支撑的路线。

**保留的错误表述**：以上"原表述"整段未被删除，用于追溯"缩写 → 误分类 → 长期未证伪"的完整链条；订正后的模型归属以路线 ① 为准，完整论证见 [模型篇章/OpenDDE](../模型篇章/OpenDDE/README.md) §3.2、§5.3。

### 路线 ④：分层等变表征（ATOMICA）

**核心思想**：不急于生成，先把全原子几何**表征**好。直接接收任意两个相互作用分子的全原子坐标，构建分层几何图（原子级 → 化学块级（氨基酸/核苷酸）→ 分子界面级），用 **SE(3)-等变网络**做结构感知消息传递，从距离/角度直接学习氢键、范德华力等相互作用。

**训练范式**：自监督去噪 + 掩码化学块预测，嵌入由等变 GNN 从头学，输出连续分层嵌入；等变性使模型对旋转平移天然鲁棒，免去"姿态记忆"负担。

**定位**：界面相互作用建模与表征的骨干，下游可接设计任务；生成并非其主打。

## 6. 贯穿全局的结论（综述论点素材）

1. **扩散是共同底座，分歧全在表示层**：四条路线都用扩散/流匹配，但"扩散作用在什么表示上"（原始坐标 / 连续 latent / 离散 Token / 等变几何图）才是路线分野的本质。
2. **"压 vs 展"是表示层的分水岭**：压（AnewOmni 把整体压进 latent）换取统一维度与高效生成；展（OpenDDE、ATOMICA 显式铺开）换取原子级细节与界面精度。没有统一最优解，只有任务适配。
3. **Embedding 全是"自学"，差别只在监督信号**：没有模型在查现成词表——2026 年 `rfd4-proteina` 模型靠物理力场（微调期 Rosetta 能量损失）、OpenDDE 靠界面形状互补损失、AnewOmni 靠 VAE 数据分布、ATOMICA 靠等变对称性、AF3/Mol-1 靠端到端结构监督。监督信号决定了 latent 的物理保真度。
4. **MSA 只在「还原自然」时必要**：预测类模型（AF3/Mol-1/OpenDDE）依赖进化共进化信号；生成/设计类面对自然界不存在的"孤儿骨架"，MSA 检索失效，转而直接学底层物理化学规律。
5. **物理先验与数据驱动协同**：显式能量监督（2026 年 `rfd4-proteina` 模型）、等变对称性（ATOMICA）、显式形状互补损失（OpenDDE）都是用先验引导数据驱动模型，避免纯高维优化陷阱。
6. **从单链到多分子系统**：OpenDDE、ATOMICA、Mol-1（蛋白/DNA/RNA/配体/离子/共价键一体建模）都指向复合物级建模，评测体系也随之演进（FoldBench-AB、MGBench、PoseBusters、MolBench-Peptide-26、PackBench）。
