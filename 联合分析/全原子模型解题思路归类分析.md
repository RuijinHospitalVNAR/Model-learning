## 1. 分析目的

AlphaFold3、Mol-1 以及 RFD4-Proteina、OpenDDE、AnewOmni、ATOMICA 等模型都以 diffusion 深度参与、面向**全原子（all-atom）**表示。但"让模型直接训练/生成每个原子的 x,y,z 坐标"非常困难，各模型给出了不同的解题思路。本文将这些思路归类、逐一分析，并给出综述写作的章节建议。

## 2. 共同难题：为什么"直接全原子坐标训练"难

1. **维度灾难**：每个原子 3 个坐标，一个复合物动辄数千至数十万原子，输出空间维度爆炸、训练数据相对稀疏；
2. **原子数可变**：不同残基/分子所含原子数不同，难以直接组织成规则张量；
3. **物理约束复杂**：键长、键角、手性、空间碰撞（steric clash）等规则必须满足，直接回归极易产生非法结构；
4. **对称性负担**：分子可任意旋转平移，模型必须处理 SE(3) 等变性，否则浪费容量去"记住姿态"；
5. **长程相互作用**：界面与远程残基间存在复杂空间依赖；
6. **计算成本**：原子级注意力/消息传递的显存与算力开销随规模急剧增长（Mol-1 实测显存随 token 数接近二次方增长）。

## 3. 归类框架总览

按**表示层策略**（如何绕开"一次性直接回归全部原子坐标"）可分为四大路线：

| 路线 | 代表模型 | 核心策略 | 一句话概括 |
| ---- | -------- | -------- | ---------- |
| ① 全原子直出 | AlphaFold3、Protenix→Mol-1 | 扩散模型在**原始坐标空间**逐步去噪，主干网络提供条件表示 | "不压缩不离散，让去噪慢慢来" |
| ② 连续隐空间压缩 | RFD4-Proteina、AnewOmni | 把（部分）原子压缩为**连续 latent**，在隐空间做流匹配/扩散，再解码回坐标 | "先压缩再生成" |
| ③ 离散结构 Token 化 | OpenDDE | 把主链/侧链拆为**离散 Token 图节点**，图网络推理后由扩散映射回坐标 | "把分子当语言来推理" |
| ④ 分层等变表征 | ATOMICA | **SE(3) 等变 GNN** 分层几何图 + 自监督去噪/掩码预测（表征为主） | "先把几何看懂，再谈生成" |

## 4. 各路线详解

### 路线 ①：全原子直出（AF3 / Protenix / Mol-1）

**核心思想**：不做隐空间压缩、不做离散化，让扩散模型直接在原子坐标上加噪–去噪；几何推理的重担交给主干（MSA module → Pairformer 的 token/pair 表示），扩散模块只负责"在条件引导下把坐标画准"。

**关键技术**：
- **AF3**：主干提取进化与序列上下文 → 扩散模块直接生成全部原子坐标；**不依赖物理力场损失**，靠数据规模 + 多样本采样 + 置信度网络排序来保证质量；
- **Mol-1**（依据官方仓库 README，已核实）：延续 Protenix/AF3 路线；蛋白 MSA 走 ColabFold MMseqs2 服务、模板走 HMMER 搜索 + kalign 对齐；每个 seed 扩散采样多个样本，按 `ranking_score` 排序输出（`sample_0` 即最优）；输出逐 token PAE 矩阵与 plddt 置信度；显存随 token 数接近二次方增长，靠多级 chunking（trunk/confidence/diffusion 各自可控）支撑 ~1500 tokens（95 GiB GPU），更大体系换 `--trimul_kernel torch` + expandable segments；
- **原子数可变的处理**：残基内原子 token 化/类型化坐标编码，使不规则原子集合同一化为规则序列。

**回应难题的方式**：扩散把"一步回归"拆成几百步小修正，缓解维度灾难与物理约束违背；多样本+置信度排名替代单点最优。

**代价**：推理成本高（多步去噪 × 多样本）；物理合理性靠数据学出而非硬约束，罕见化学仍可能翻车。

### 路线 ②：连续隐空间压缩（RFD4-Proteina / AnewOmni）

**核心思想**：把难学的高维原子坐标压进低维连续隐空间，生成在隐空间完成，再解码回全原子。

**两个代表的不同取舍**：
- **RFD4-Proteina**：**主链保持显式坐标**（锚原子 N/CA/C/O），仅把**侧链压成 32 维 latent**；专用自编码器学习该 latent，**解码受 Rosetta 能量函数显式监督**（确定性物理驱动向量）；生成用部分隐变量流匹配（Partially-latent Flow Matching）。原子数可变不靠虚拟原子填充掩盖，而是把化学身份+构象编进 latent、解码强制还原真实拓扑，因此侧链失真反而更低——PackBench 侧链打包误差约 0.82 Å，接近实验精度。
- **AnewOmni**：**整体压缩**。按化学先验做分层"积木块（Building Blocks）"拆解——标准氨基酸/核苷酸直接保留；小分子与非天然氨基酸拆为数据库高频片段；罕见子结构兜底拆到单原子；再用**全原子 VAE** 把积木块几何压进连续共享隐空间（概率分布，非 VQ、无离散词表），在光滑隐空间做扩散后解码。跨模态泛化强（小分子↔多肽↔抗体），但原子级侧链精度弱于专用打包工具；物理约束偏隐式，需后验证。

**回应难题的方式**：降维解决维度灾难与计算成本；解码器（物理监督 / VAE 数据分布）兜住物理合理性。

**代价**：压缩必有信息损失；latent 与物理约束的平衡需精细调优（RFD4）/依赖数据分布、隐式约束（AnewOmni）。

### 路线 ③：离散结构 Token 化（OpenDDE）

**核心思想**：把残基显式展开为 **Backbone Token 与 Side-chain Token** 等独立图节点，用图网络 + Pair-conditioned Attention / 三角更新让 Token 相互"协商"几何一致性，最后仍需底层扩散生成器映射回三维坐标，并做 steric clash 后处理。

**特点**：借鉴 AF 的 Pairformer，对天然复合物保留进化信号（MSA），面向**多分子共折叠预测**（蛋白–核酸–配体，如抗体–抗原）；结构 Token 化降低建模复杂度、便于多模态统一（结构/序列/配体 Token 同框架）。

**代价**：Token 离散化在"还原精确坐标"时丢失高频几何细节，必须靠扩散生成器+后处理找补；图网络训练复杂度高。

### 路线 ④：分层等变表征（ATOMICA）

**核心思想**：不急于生成，先把全原子几何**表征**好。直接接收任意两个相互作用分子的全原子坐标，构建分层几何图（原子级 → 化学块级（氨基酸/核苷酸）→ 分子界面级），用 **SE(3)-等变网络**做结构感知消息传递，从距离/角度直接学习氢键、范德华力等相互作用。

**训练范式**：自监督去噪 + 掩码化学块预测，嵌入由等变 GNN 从头学，输出连续分层嵌入；等变性使模型对旋转平移天然鲁棒，免去"姿态记忆"负担。

**定位**：界面相互作用建模与表征的骨干，下游可接设计任务；生成并非其主打。

## 6. 贯穿全局的结论（综述论点素材）

1. **扩散是共同底座，分歧全在表示层**：四条路线都用扩散/流匹配，但"扩散作用在什么表示上"（原始坐标 / 连续 latent / 离散 Token / 等变几何图）才是路线分野的本质。
2. **"压 vs 展"是表示层的分水岭**：压（RFD4、AnewOmni 把侧链/整体压进 latent）换取统一维度与高效生成；展（OpenDDE、ATOMICA 显式铺开）换取原子级细节与界面精度。没有统一最优解，只有任务适配。
3. **Embedding 全是"自学"，差别只在监督信号**：没有模型在查现成词表——RFD4 靠物理力场、OpenDDE 靠图几何一致性、AnewOmni 靠 VAE 数据分布、ATOMICA 靠等变对称性、AF3/Mol-1 靠端到端结构监督。监督信号决定了 latent 的物理保真度。
4. **MSA 只在「还原自然」时必要**：预测类模型（AF3/Mol-1/OpenDDE）依赖进化共进化信号；生成/设计类面对自然界不存在的"孤儿骨架"，MSA 检索失效，转而直接学底层物理化学规律。
5. **物理先验与数据驱动协同**：显式能量监督（RFD4）、等变对称性（ATOMICA）、clash 后处理（OpenDDE）都是用先验引导数据驱动模型，避免纯高维优化陷阱。
6. **从单链到多分子系统**：OpenDDE、ATOMICA、Mol-1（蛋白/DNA/RNA/配体/离子/共价键一体建模）都指向复合物级建模，评测体系也随之演进（FoldBench-AB、MGBench、PoseBusters、MolBench-Peptide-26、PackBench）。
