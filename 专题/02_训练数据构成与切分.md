## 1. 专题目标

- 把"训练数据"从背景段提升为独立判断轴：**同一架构换数据，性能可以差一个档；同一数据换架构，差距往往小于宣传。**
- 给出一份可执行的核查顺序：切点 → 去冗余 → 相似度排除 → 质量过滤 → 配比／蒸馏 → 许可。
- 明确抗体／纳米抗体数据的结构性稀缺（VNAR 仅 84 个结构），为 `04` 专题的可迁移性判断提供数字依据。

### 2.2 数据配比、合成数据与自蒸馏

- **AF3**：论文明确使用 AF-Multimer v2.3 预测结构做交叉蒸馏，以抑制幻觉。【论文自称】
- **Boltz-1**：加入 OpenFold 蒸馏约 270K 结构。【论文自称】
- **Boltz-2**：加入 MD 集合（MISATO／ATLAS／md-CATH）与 AF2／Boltz-1 蒸馏；亲和力数据来自 PubChem／ChEMBL／BindingDB + HTS + 片段 + 二元标签。【论文自称】
- **BoltzGen**：PDB + AFDB（AF2 自蒸馏）+ Boltz-1 自蒸馏结构。【论文自称】
- **La-Proteina**：AFDB 子集，最多 46M 结构-序列对。【论文自称】
- **Proteina-Complexa**：Teddymer——用单体预测结构的 domain-domain 交互构造合成 binder-target 对，规模 >1M。【论文自称】
- **ESM3**：2.78B 序列、771B unique tokens；官方称使用数百 million 合成（预测结构／功能）数据扩增。【论文／官方博客】
- **AnewOmni**：>5M 生物分子复合物（蛋白-小分子／肽／抗体）。【核实：摘要】

**自蒸馏的真实风险（【推断】）：**

1. **误差放大**：教师模型的系统性偏差（如手性违规、clash、CDR3 过度刚性）会被学生继承并放大。
2. **分布收窄**：预测结构比实验结构更"干净"、更单一构象，学生会失去对柔性／多构象的建模能力。
3. **评价污染**：如果测试集结构在教师模型的训练集中，蒸馏等于间接泄漏。
4. **规模幻觉**："46M 结构-序列对"里有多少是预测结构，论文往往不拆开报；这直接影响对"数据红利"的归因。

**目前没有检索到一篇明确讨论"自蒸馏导致误差放大"的论文。** 这属于本专题的判断，不是文献结论。【未核实】

**一条可对照的取舍实例：Pallatom2 主动放弃数据蒸馏。** 它的训练语料是 AFDB + TED（内部处理版），保留原始序列、不做 ProteinMPNN 重设计，也不做 refold 一致性过滤；作者自述代价是 designability 低于同期蒸馏路线，收益是氨基酸组成更接近自然蛋白（详见 [模型篇章/Pallatom2 §4](../模型篇章/Pallatom2/README.md)）。读这条实例要注意两点：① 报告写 "trained without distilled data"，但 AFDB 本身是 AF2 的预测产物，该句只能读作"没有再叠加重蒸馏"，不能读作"未使用任何模型生成结构"；② 训练集规模、清洗阈值、时间切点、聚类切分与 held-out 均未披露，因此无法量化这条取舍的净收益。它的价值不在结论，而在把"蒸馏增益 vs 分布偏移"的权衡显式化了：用蒸馏换 designability，等于把 ProteinMPNN／refold 的偏好写进训练分布；不用蒸馏则保留原始序列分布，但放弃那部分增益。【论文自称 + 推断】

## 3. 清洗、去重与切分

### 3.1 去冗余与切分协议

| 协议 | 做法 | 适用 | 出处 |
|---|---|---|---|
| 序列聚类 | 30% 序列同一性（RFAA）；40% MMseqs（AF3 评测／Boltz-1 验证测试） | 通用蛋白去冗余 | 【核实】 |
| 抗体克隆去冗余 | CD-HIT 95% → 2,436 簇（IgGM） | 抗体结构 | 【核实】 |
| 时间切分 | SAb23H2（2023 下半年）作为测试；AF3 Recent PDB 只取切点之后 | 抗体／复合物 | 【核实】 |
| 配体相似度排除 | Tanimoto ≤0.8（Boltz-1） | 蛋白-配体 | 【论文自称】 |
| 抗体专用切分 | SAbDab2 `ab-split`（只看抗体序列相似度）与 `ab-ag-split`（同时看抗原序列相似度） | 抗原无关／抗原感知任务 | 【核实：Zenodo 0.3.0】 |
| 按分辨率分组 | 评测时按 ≤2.5 Å／2.5–4 Å／4–9 Å 分组 | 检验低分辨率能力（V2） | 本专题建议 |

**SAbDab2 的两套切分是目前抗体领域最明确的分割协议。** 做 VNAR 基准时还应在 `ab-ag-split` 之上再加"单域 + 物种（shark）"筛选。【核实 + 推断】

### 3.2 泄漏：不止是"训练集里有没有这个结构"

已知的防泄漏做法：

- AF3 为 PoseBusters 单独训练了一个 **2019-09-30 切点**的模型，而不是用主模型；Recent PDB 评测集只取 2021-09-30 之后释放的结构。【论文自称】
- Boltz-1 测试集取 2023-01-13 之后，并与之前结构做蛋白／配体相似度排除；验证／测试用 MMseqs 40% 聚类。【论文自称】
- IgGM 用时间切分 SAb23H2（2023 下半年），而不是随机切分。【核实】

**仍然存在的隐性泄漏渠道（【推断】，但有明确事实基础）：**

1. **同一 PDB 条目的多个版本**：同一实验在不同分辨率／不同构象下多次 deposition，随机切分会把同一克隆分到训练和测试。
2. **同一抗体克隆的多个结构**：SAbDab 按结构计数，同一抗体可能有 10+ 个结构。
3. **同一抗原的近似结构**：`ab-split` 不排除抗原相似性，做抗原感知任务时会泄漏。
4. **预测结构蒸馏**：用 AF2／Boltz-1 预测结构扩充训练集，若测试集也含这些预测结构的模板，等于把测试信息提前注入。
5. **评价集本身的"训练集化"**：PoseBusters、CASP15 靶标在后续模型训练时可能已被纳入，但很多论文不重新切点。

**结论：判断一个模型的"泛化"宣称，第一件事不是看指标，而是看它的测试集发布日期是否晚于训练切点，以及是否做了抗原／配体层面的相似度排除。** 对应 `01 §7.3` 判据 1、2 与 `03` 的 V1、V10。

### 3.3 结构质量与异常处理

| 问题 | 主流做法 | 可核实来源 |
|---|---|---|
| 缺失原子 | 只保留实验观测到的原子，用 `is_missing` 标记；训练时 mask 或忽略 | AF2 mmCIF parser（代码可核实） |
| 链断裂 | 按链／片段切分；长缺失区域不强行补 | AF2 parser；AF3 输入 atomization |
| 低分辨率 | 各模型阈值不同：Boltz-1 论文 9 Å、代码 4.0 Å；RFAA 未明示 | 【核实：论文 vs 配置】 |
| altloc | 多数流程交给 BioPython／OpenStructure；未见论文明确策略 | 【未核实】 |
| 非标准残基 | AF3 显式建模 modified residues；Boltz／Chai 支持配体、核酸、糖基化 | 【论文自称】 |
| 配体／金属／核酸 | AF3 系显式 token 化；RFAA 原子级；Chroma／Proteina 不支持 | 【核实】 |

### 3.4 一个被低估的问题：低分辨率 + 长 CDR3

纳米抗体的 CDR3 经常是结构中最灵活、缺失原子最多的区域；如果按 4 Å 甚至 9 Å 过滤，训练集中能保留的 CDR3 几何非常有限。【推断，依据 SAbDab-nano 的 X-ray／EM 比例与分辨率分布】

这解释了为什么"低分辨率口径"不只是数据质量问题，而是**直接削掉抗体最难的那部分监督信号**。Boltz-1 论文 9 Å 与代码 4.0 Å 的差异（见 §3.3）对普通复合物影响有限，对抗体 CDR 的影响需要单独测（V2 只测了通用复合物，抗体子集应另做）。

## 4. 覆盖与偏置

### 4.1 抗体／纳米抗体数据：稀缺是结构性的，不是暂时的

| 数据集 | 规模 | 日期 | 来源性质 |
|---|---|---|---|
| SAbDab | 10,840 结构；8,633 含配对 VH/VL；21,285 Fv；10,200 带抗原；735 有亲和力数据 | 2026-05-28 | 【核实：官网统计页】 |
| SAbDab-nano | 2,246 单域结构；4,684 Fv；2,114 带抗原；86 有亲和力数据 | 2026-05-28 | 【核实：官网统计页】 |
| SAbDab2 ML Dataset | 16,415 结构／8,992 PDB／5,556 unique antibodies | v0.3.0，2026-10-13 | 【核实：Zenodo】 |
| 其中 VNAR | 84 个结构（67 带抗原 + 17 无抗原），占 0.5% | 同上 | 【核实】 |
| 其中 VHH-like 单域 | 3,427 个结构（2,156 带抗原） | 同上 | 【核实】 |
| PLAbDab-nano | 4,913 条 VHH + VNAR 序列，来自 796 项研究 | 2024 | 【核实：NAR 论文摘要】 |
| OAS | >10 亿序列、>80 研究；2022 年论文报 3.5B 序列，配对仅 121,838 | — | 【官网／论文】 |

**三个硬约束：**

1. **VNAR 只有 84 个结构。** 这不足以训练一个从零开始的结构生成器，也不足以做可靠的留出评估。任何"VNAR 专用全原子模型"的宣称，都必须说明它用了什么预训练迁移。
2. **OAS 只有序列，没有坐标。** 用它做结构监督必须经过预测结构，等于引入自蒸馏偏差。
3. **框架与抗原偏差。** 抗体结构高度偏向少数胚系（IGHV1-69、IGHV4-39 等）与免疫优势抗原；VNAR 的框架与 VHH 不同，且没有 CDR2、CDR3 更长、常含非经典半胱氨酸。【领域共识 + 推断】

### 4.2 其他偏置

- **化学覆盖**：RFAA 用 46 种元素 token、键级 token 覆盖小分子／金属；AF3 系按原子类型 token 化。糖基化、修饰残基的覆盖仍不均衡。【核实 + 推断】
- **构象覆盖**：PDB 以晶体结构为主，柔性区域与多构象样本少；自蒸馏会进一步收窄分布（§2.2）【推断】。
- **物种覆盖**：抗体数据以人／鼠为主，鲨鱼（VNAR）占 0.5%，骆驼科（VHH）约 20%（3,427/16,415）【核实：由 SAbDab2 数字推算】。
- **任务覆盖**：结构预测模型的数据以"单体 + 复合物"为主，binder 设计所需的"靶标-结合体配对"大量依赖合成（Teddymer）而不是实验【论文自称】。

## 5. 许可与可获取性

### 5.1 公开透明度分级

| 等级 | 含义 | 代表模型 |
|---|---|---|
| A：论文 + 训练配置 + 权重都可核实 | 可复现训练管线 | Boltz-1／Boltz-2（MIT + `full.yaml`）；RFAA（权重 + 代码）；BoltzGen（MIT + 代码）；Proteina-Complexa（Apache-2.0 + 权重）；AnewOmni（MIT + 权重）；IgGM（MIT + CC-BY 权重） |
| B：论文 + 代码 + 权重，但训练数据细节不完整 | 可复现推理，难复现训练 | AF3（代码 + 权重，切分论文有但管线未全开）；Chai-1（代码 + 权重，切点未披露）；Protenix v1（代码开放，v2 权重专有） |
| C：论文 + 代码，权重受限或需申请 | 可读不可跑 | Chroma（权重需 API key）；ESM3（1.4B 开放，98B 闭源）；TorchCraft（代码开放、依赖 AF3 权重） |
| D：仅论文／项目页，代码或权重不全 | 只能读 | AntiBMPNN（数据集规模未披露）；OpenFold3（preview）；SeedProteo（未核实） |
| E：无法核实 | 不应用于决策 | 名称／版本存疑的工作 |

**Boltz-1 是当前透明度最好的样本，但它恰好暴露了一个典型问题：论文写 9 Å，代码写 4.0 Å。** 这不是造假，而是"论文声明"与"实际训练配置"之间的常见漂移；做复现时必须以代码为准。【核实】

### 5.2 许可要点

- **可直接用于训练／商用**：Boltz（MIT）、BoltzGen（MIT）、AnewOmni（MIT）、IgGM（MIT 代码 + CC-BY 4.0 权重）、Proteina-Complexa（Apache-2.0）。
- **代码开放、权重受限**：AF3（`WEIGHTS_TERMS_OF_USE`）、Chai-1（Apache-2.0 代码 + 权重）、Chroma（权重需申请）、Protenix（v2 权重专有）。
- **非商用**：ESM3 1.4B（非商用许可）；98B 仅 API。
- **数据许可**：APM 使用 CC-BY 数据；SAbDab／SAbDab2 的再分发条款需单独确认（Zenodo 条目注明许可）。【未逐条核实】

## 7. 结论与开放问题

- **数据的第一判据是切点，不是规模。** 同一切点（2021-09-30）让 AF3／Boltz-1／Protenix 具备可比性；跨切点（Boltz-2 2023-06-01）的亲和力与结构指标不应直接横比。
- **抗体的瓶颈是"克隆级切分 + 结构数量"，不是模型容量。** VNAR 84 个结构决定了任何 VNAR 专用模型都必须是迁移学习，而不是从零训练。
- **自蒸馏是当前最大的数据红利，也是最大的不可见风险。** 论文普遍不拆分"实验结构／预测结构"，导致"数据红利"无法归因；V10 是唯一能本地验证的办法。
- **公开透明度呈两极：** MIT/Apache 系列（Boltz、BoltzGen、AnewOmni、IgGM、Complexa）可复现训练；Chai-1 切点不披露、Protenix v2 权重专有、ESM3 98B 闭源，属于"可读不可复现"。
- 开放问题：① 是否有不依赖自蒸馏的等量数据方案；② 低分辨率过滤对抗体 CDR 的真实影响（§3.4，尚无公开量化）；③ SAbDab2 正式论文（bioRxiv 2026.06.16.732554）发表后切分协议是否会变；④ 糖基化／修饰残基的覆盖是否足以支撑 VNAR 的非经典 Cys。
