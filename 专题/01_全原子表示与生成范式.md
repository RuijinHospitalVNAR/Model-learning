## 1. 专题目标

- 建立**领域级**技术判断，而不是针对单一项目选型。
- 回答三件事：表征粒度如何迁移、生成范式谁在取代谁、条件控制的进步发生在哪一层。
- 为后续抗体／VNAR 选型提供判据：按"是否真的生成侧链原子坐标与原子类型"判断，而不是按宣传词判断（见 §2.4 与 03 专题）。
- 一句话总判断：**2023–2026 的主线不是"更大的模型"，而是"表征粒度上移 + 生成范式换代 + 条件接口标准化"三件事同时发生；性能提升中相当大的比例来自数据构造（尤其蒸馏结构与合成复合物），而不是网络结构本身。**【推断，依据见 §7 归因表】
- **本轮改动（2026-11-10）**：分类骨架由「四路线」换成三条正交轴——表征粒度 × 生成范式 × 条件接口。四路线叙述不删，归档为 §2.5 的历史分类并写明弃用理由；覆盖矩阵按新轴重排（§6），数值未改。

## 2. 技术谱系与表示层

### 2.1 四次迁移，而不是模型清单

**迁移一：残基 frame → 原子 token（2023–2024）**

- 2022–2023 第一代生成器以**残基**为基本单位：主链 Cα 坐标 + N–Cα–C 刚性 frame，侧链靠后处理（ProteinMPNN 逆折叠 + 侧链 packing）。RFdiffusion（Watson et al., *Nature* 2023）是这一代代表，只处理蛋白主链。
- **Chroma**（*Nature* 2023）做了半步：主链仍是残基级图扩散，序列与侧链交给独立 design network 以骨架为条件解码，最终结构是 all-atom，扩散过程不是——"两段式全原子"。
- **RFAA / RFdiffusion-AA**（Krishna et al., *Science* 2024, DOI 10.1126/science.adl2528）完成关键一跃：蛋白／核酸按残基表示，小分子、金属、非天然氨基酸、共价修饰按**原子**表示，两类 token 在同一网络联合去噪。【核实：论文正文与 `baker-laboratory/RoseTTAFold-All-Atom`、`baker-laboratory/rf_diffusion_all_atom`】
- **AlphaFold 3**（*Nature* 2024, 630:493–500）走更彻底的路：聚合物每残基 1 token，配体／离子每原子 1 token；扩散头直接在 `(n_token, max_atoms_per_token, 3)` 上做 atom cross-attention，**取消 frame、取消侧链扭转角**。【代码／配置核实：`alphafold3/model/network/diffusion_head.py`】

驱动力不是精度，而是**化学覆盖面**：frame 表示对配体、金属、修饰残基非常别扭；只要目标包含小分子或共价键，残基级就必须打补丁。反过来一旦放弃 frame，就必须用海量旋转增强与原子级监督补偿等变性——这是后面所有 AF3 系模型的共同代价。【推断】

**迁移二：SE(3) diffusion → EDM x0 diffusion → flow matching**

1. **SE(3) diffusion（RFdiffusion / RFAA）**：在刚性 frame 上加噪，网络预测 x0，损失用 all-atom FAPE。几何归纳偏置强、样本效率高；实现复杂、对非聚合物不自然。
2. **EDM 式欧氏扩散（AF3 / Boltz-1 / Chai-1 / Protenix）**：对每 token 原子坐标加高斯噪声，`σ_data=16`、`σ_min=4e-4`、`σ_max=160`、`ρ=7`，网络输出 **x0**，采样默认 **200 步**。没有显式等变网络，靠随机旋转平移增强与坐标回归学出来。【代码／配置核实：AF3 与 Boltz 的 `diffusion_process_args`】
3. **Flow matching（Proteina / La-Proteina / APM / Proteina-Complexa）**：学噪声到数据的直线速度场，推理步数更少、训练更稳。Proteina 是主链 flow matching；La-Proteina 是"部分隐式"flow matching（Cα 显式 + 每残基隐变量）；Proteina-Complexa 是潜空间 flow matching + 推理期搜索。【论文自称】
4. **离散掩码生成（ESM3）**：不是连续扩散，而是三轨离散 token 的掩码语言模型，迭代 unmask；结构轨用 VQ-VAE 把局部几何压成每残基 1 token（码本 4096）。【论文／模型卡】
5. **离散 + 连续混合扩散（IgGM）**：序列用 20 氨基酸离散扩散，结构用 Cα／SO(3) 连续扩散，再用 consistency model 降步数。【论文自称】

判断：**flow matching 正在取代 EDM 扩散成为新模型默认选择，但"取代"目前主要是训练／采样效率，不是精度上限。** AF3 系 200 步扩散仍是结构预测精度基准；flow matching 目前主要在生成任务上展示优势。【推断】

**迁移三：微调式条件 → 可组合条件 → 约束语言**

- **第一代（微调式）**：RFAA 固定配体原子坐标、蛋白从噪声去噪；AF3 口袋条件需**单独微调一个模型**。条件与模型绑定，换任务要重训。
- **第二代（可组合能量项）**：Chroma 把对称性、子结构、形状、CATH 类别做成可组合 conditioner，用能量项 + 退火 Langevin 采样，**不重训**即可切换条件——架构层面的真创新。
- **第三代（统一约束语言）**：BoltzGen 把结合位点、二级结构、共价键、靶标构象写成统一规范；Chai-1 原生支持 restraints／共价键／表位；AnewOmni 用 graph prompt 支持环化、指定 motif、非天然残基、锚定残基、片段生长。
- **CFG（classifier-free guidance）**：AnewOmni、Proteina 系明确使用；RFAA 原文未核实使用 CFG。代价是每次采样多一次前向，guidance scale 过大会牺牲多样性。【论文／代码核实】

**迁移四：评价标准从 RMSD → 可设计性 → 湿实验命中率**

2022–2023 看 RMSD／LDDT／DockQ；2023–2024 看 self-consistency（生成序列用 AF2／ProteinMPNN 重折叠）、设计率、多样性；2025–2026 看湿实验 hit rate、Kd／IC50、晶体结构 RMSD。Proteina-Complexa 报 133 靶、>100 万候选；AnewOmni 报 KRAS G12D／PCSK9 多模态命中率；BoltzGen 报纳米抗体与肽的湿实验。**指标越来越"强"，可比性越来越差**——不同工作的靶标、筛选通量、表达系统、命中定义都不同，"75% hit rate"与"63.5% hit rate"不能直接比较。评测口径冲突与复现设计见 `03_评测体系与可复现性.md`。

### 2.3 等变性的三种实现与两块短板

1. **显式等变网络**：RFAA 用 SE3Transformer；Chroma 用随机 SE(3) 等变图网络；AnewOmni 用 E(3) 等变潜扩散。【论文／代码核实】
2. **局部 frame + 不变特征**：RFdiffusion／RFAA 的 Cα frame；Proteina 无残基 frame、非等变，每残基单点 Cα（`x∈R^{3L}`）。【论文／代码核实】
3. **不做等变，用数据增强**：AF3 系（AF3／Boltz／Chai／Protenix）靠随机旋转平移增强 + 坐标回归。这是最工程化、也最容易被误读为"没有几何归纳偏置"的做法。【代码／配置核实】

**短板一：手性。** RFAA 显式编码 R/S；AF3 系没有显式手性约束，论文自己报告 **4.4%** 手性违规。【核实】
**短板二：对称性。** Chroma 里对称性是一等 conditioner，AF3 系里是推理期 symmetry correction（Boltz 配置 `symmetry_correction: true`），不是训练目标。【核实】

### 2.4 谁解决了什么、谁被取代、哪些路线走死

| 问题 | 谁解决了 | 现状 | 依据 |
|---|---|---|---|
| 配体／金属／修饰残基的统一建模 | RFAA（混合原子／残基表示）；AF3（token 化原子读出） | 已成为事实标准；纯蛋白模型不再被视为"全原子" | 【核实】 |
| 侧链的全原子生成 | Chroma 两段式；La-Proteina 隐变量；AnewOmni block VAE | 仍无低成本、显式、变长侧链的完美方案 | 【论文自称】+【推断】 |
| 条件可组合、免重训 | Chroma 的能量 conditioner | 被后续模型部分吸收，但多数模型仍回到"约束输入 + 微调" | 【核实】 |
| 设计＋预测统一 | BoltzGen（design as structure prediction） | 2025 后新叙事；两段式 backbone+MPNN 被弱化 | 【论文自称】 |
| 单序列、低 MSA 依赖 | Chai-1 单序列模式 + ESM embedding | 设计循环提速明显，但精度仍有代价 | 【论文自称】 |
| 抗体 CDR 共设计 | IgGM（残基级）、AntiBMPNN（逆折叠） | 仍停留在残基／主链级，未到全原子 | 【核实】 |

**被取代或边缘化的路线（【推断】，有事实支撑）：**

1. **纯 residue-level 却自称 all-atom**：抗体侧仍常见（IgGM 只生成 Cα + SO(3) frame），与"全原子"定义冲突。
2. **backbone diffusion + 独立 ProteinMPNN**：仍是最便宜的工程路线，但 2025–2026 的 SOTA 叙事里已被"单模型联合生成"压过。
3. **大规模 MSA 依赖的设计闭环**：Chai-1 证明单序列可接近 AF3，MSA 不再是不可替代的。
4. **自回归坐标生成**：除 ESM3 的离散 token 迭代外，几乎不作为结构生成主流。
5. **纯 frame 扩散用于配体**：RFAA 选择混合表示而非把配体塞进 frame。
6. **一个模态一个模型**：AnewOmni 用统一 atom-to-block 空间直接挑战这一假设。

### 2.5 历史分类：四路线为什么不再作主轴

**保留原因**：四路线是本仓库 2026-11 之前组织模型的骨架，记录的是"怎么判断"的过程，不是结论清单；删掉会让后来者看不到哪条路线被证伪、依据是什么。完整版与证伪链条见 [`联合分析/全原子模型解题思路归类分析.md`](../联合分析/全原子模型解题思路归类分析.md)，此处只留索引表与弃用理由。

| 历史路线 | 分类依据 | 当前成员（已核实） | 现状 |
|---|---|---|---|
| ① 全原子直出 | 在原始坐标空间逐步去噪 | AF3 系（AF3／Boltz-1/2／Chai-1／Protenix／OpenFold3）、Mol-1、Pallatom2、OpenDDE | 成立 |
| ② 连续隐空间压缩 | 先压进连续 latent，再在隐空间生成 | AnewOmni（单例） | 只剩单例，不构成路线 |
| ③ 离散结构 Token 化 | 主链／侧链拆成离散 Token 图节点，图推理后由扩散映射回坐标 | 无（原记 OpenDDE，2026-11-06 订正至 ①） | 判死：无已核实成员 |
| ④ 分层等变表征 | SE(3) 等变分层几何图 + 自监督去噪／掩码预测 | ATOMICA | 成立，但与 ① 不在同一维度 |

**为什么弃用（三条，均以本仓库已有证据为准）**

1. **③ 的问题是证据不足，不是记错。** 唯一候选 OpenDDE 的"结构 token"经代码核实是连续隐节点 `s_u ∈ R^c`，无码本、无离散采样，采样空间仍是 `R^{N_atom×3}`。要复活 ③，缺的不是再找一个"名字像离散"的模型，而是"同一主干、只换采样空间"的对照实验——本仓库目前既无该实验，也无第二个候选。
2. **② 只剩 AnewOmni 一个成员。** 单例无法区分"路线"与"实现选择"；它被判为 ② 的唯一依据是"有 VAE 潜空间"，而它的生成仍是在潜空间做扩散再解码——压不压、压到哪一层是一个连续刻度，不是互斥选项。
3. **① 与 ④ 是同一根轴上的两段，不是对立选项。** ① 说的是"在坐标空间采样"，④ 说的是"先把几何表征好、不急着采样"。ATOMICA 不生成，把它与生成器并列，等于把"任务不同"误记成"策略不同"。

**归纳**：四路线的分类依据是"如何绕开一次性回归全部坐标"，这个问题的前提是**必须生成**。一旦把非生成式模型纳入（ATOMICA、AntiBMPNN、TorchCraft），该依据就退化为"你在做哪类任务"，无法再充当分类轴。这是骨架失效的根因，不是成员不够。

**新骨架为什么能撑住**：三条轴各自回答一个独立的判定问题（定义见 §6.1），23 个条目在每条轴上都有唯一取值；新增成员时只需填三个格，不必先裁决"它属于哪条路线"——旧骨架最容易返工的地方正在这一步。

## 4. 生成范式对照

| 范式 | 代表 | 噪声／时间 | 网络输出 | 主损失 |
|---|---|---|---|---|
| SE(3) diffusion | RFdiffusion、RFAA | frame 上的旋转 + 平移扩散 | x0 | all-atom FAPE + pLDDT/PAE |
| EDM 欧氏扩散 | AF3、Boltz-1/2、Chai-1、Protenix | σ_min 4e-4、σ_max 160、σ_data 16、ρ=7 | x0 | 去噪 MSE + distogram + 置信头 |
| Correlated diffusion | Chroma | 噪声匹配天然蛋白距离统计 | x0 | 去噪 + 设计网络 |
| Flow matching | Proteina、La-Proteina、APM、Proteina-Complexa | 直线概率路径 | 速度场 | CFM loss |
| 离散掩码 LM | ESM3 | 掩码比例 | token 分类 | 交叉熵 |
| 离散 + 连续扩散 | IgGM | 序列离散、结构连续 | 序列 logits + Cα/SO(3) | 离散 CE + 连续去噪 |
| 推理期优化 | TorchCraft、FlexEvo | 无训练 | 序列 logits／构象编辑 | 冻结预测器置信度 + 几何目标 |

**一个常见误读：** "预测 x0"与"预测噪声"数学上可互相转换，但大噪声区间数值稳定性不同。AF3 系与 RFAA 都选 x0，是因为坐标尺度固定、FAPE／RMSD 类损失直接可用；flow matching 学速度场，等价于在概率路径上做回归。【推断，依据各仓库损失实现】

**采样与规模化（细节见 03 专题）：** AF3／Boltz 默认 200 步；RFAA 代码示例 T=100（纯配体）／T=200（配体+motif）；Chai-1 默认 5 个样本；AF3 论文默认 5 seeds × 5 samples = 25 个样本取 top-1，而抗体任务需约 **1000 seeds** 才饱和。【代码／配置核实 + 论文自称】

## 5. 条件控制对照

| 接口 | 代表模型 | 实现方式 | 代价 |
|---|---|---|---|
| 固定原子 + contig | RFAA | 配体原子坐标固定，蛋白从噪声去噪 | 换口袋要重新给坐标；无 CFG |
| 可组合能量项 | Chroma | symmetry／substructure／shape／class 能量 + 退火 Langevin | 每加一个条件多一项能量，调参成本高 |
| 口袋微调 | AF3 | 单独训练 pocket-conditioned 模型 | 多一套权重 |
| 统一约束语言 | BoltzGen、Chai-1 | pocket／SS／共价键／restraint 作为输入特征 | 需把约束编码进 featurizer |
| Graph prompt + CFG | AnewOmni | 环化、motif、非天然残基、锚定、片段生长 | CFG 双前向；prompt 设计需要领域知识 |

**关键判断：条件控制的进步主要发生在"接口"层，而不是"生成器"层。** Chroma 的能量 conditioner、BoltzGen 的约束语言、AnewOmni 的 graph prompt，本质都是把领域约束翻译成模型可读的特征；生成骨干仍是扩散／flow。真正改变生成器能力的条件创新只有少数（如 RFAA 的原子级配体固定、AF3 的 atom cross-attention）。【推断】

### 6.1 三条轴的定义与判据

| 轴 | 受控取值 | 要回答的判定问题 | 证据形态 |
|---|---|---|---|
| 表征粒度 | 逐原子／重原子／Cα 单点／latent／块级 | 网络读写的**最小信息单元**是什么？原子集合能否随化学类型扩展？ | tokenizer／原子槽位定义；论文表征节 |
| 生成范式 | 坐标扩散（x0）／流匹配（CFM）／离散 token 生成／非生成式 | 采样发生在什么空间？目标函数是什么？ | 扩散配置（σ 调度、步数）、损失实现 |
| 条件接口 | MSA／模板／序列／表位／能量项／graph prompt／固定原子 | 外部约束**以什么形式**进入网络？换条件要不要重训？ | featurizer／conditioner 代码、条件开关 |

**取值口径**（避免同一模型被两处重复归类）：

- **逐原子**：每个原子一个 token，元素类型显式，原子集合随配体／修饰／离子扩展（AF3 系、Mol-1、RFAA、BoltzGen、SeedProteo、OpenDDE、TorchCraft）。
- **重原子**：仍逐原子，但限定为无氢重原子集合，且**无键级／电荷／芳香性**（Pallatom2 的 atom14 槽位、ATOMICA 的元素 one-hot 节点）。它与"逐原子"的差别不是精度，而是**化学语义的边界**——这直接决定二硫键与非经典残基能不能表达（见 04 专题）。
- **Cα 单点／残基级**：最小单元是一个残基坐标点或一个残基 token，不是原子（Proteina 的 `x∈R^{3L}`；Chroma／IgGM／APM／AntiBMPNN／ESM3）。
- **latent**：显式隐变量承载侧链或整体几何，需解码器回到坐标（La-Proteina 的 8 维隐变量、Proteina-Complexa 的部分隐变量）。
- **块级**：原子先按化学先验聚成块（氨基酸／核苷酸／片段／离子），块是生成单元（AnewOmni 的 atom block + VAE）。ATOMICA 也有块级读出（`z_block`），但块只用于下游读取、不参与生成，故按"重原子"归类。

**为什么删掉"模型家族"列**：该列取值是"结构预测／生成／设计／逆折叠／推理期优化"，与"生成范式"的"非生成式"取值、以及"是否条件化"高度共线（预测器＝非生成式＋MSA／模板；生成器＝扩散或 CFM），在新轴下没有独立的判定问题，保留会让同一信息出现两次。**"主干"列保留但不参与分组**：它回答"怎么实现"，是实现层参考，不是分类轴。

**为什么"重原子"只剩 2 项、"块级"只剩 1 项，不算重犯 ② 的错误**：② 的失败是"单例被当作一条互斥路线"；粒度是**刻度**，成员可以摊在一条线上，单成员只说明该取值稀有，不承担"互斥策略"的论证负担。

**生成范式为什么是四类而不是三类**：坐标扩散 / CFM / 非生成式之外，ESM3 的掩码语言模型既不是坐标扩散也不是流匹配，硬塞会失真，故保留"离散 token 生成"一类。它**不是**复活历史路线 ③：③ 的主张是"离散**结构** token 图推理 + 扩散映射回坐标"，从未有已核实成员；ESM3 的离散 token 是序列／结构轨的 VQ-VAE 表示，主张不同、证据不同。

## 7. 结论与开放问题

### 7.1 架构创新 vs 工程／数据红利（归因表）

| 模型 | 性能提升主要来自 | 判断依据 | 置信度 |
|---|---|---|---|
| AF3 | 架构（atom-level diffusion + pairformer）+ 数据（PDB 全量 + AF2 蒸馏） | 相对 AF2 的结构模块替换是架构性的；蒸馏是数据性的 | 高 |
| Boltz-1 | 工程复现 + 开放数据管线 | 明确复现 AF3，主要改动是无模板、MSA 配对、pocket 条件 | 高 |
| Boltz-2 | 数据 + 任务头（亲和力） | 骨干沿用 Boltz-1，新增 affinity 头与 MD／亲和力数据 | 高 |
| Chai-1 | 架构／条件（单序列 + ESM embedding + restraint） | 与 AF3 精度接近，但接口不同 | 中高 |
| RFAA | 架构（原子／残基混合表示） | 配体／金属／共价修饰的覆盖是表示层面的 | 高 |
| Chroma | 架构（可组合 conditioner + correlated noise） | 条件切换免重训是架构性的；但成功率仍低 | 中高 |
| ESM3 | 数据（2.78B 序列）+ 表征（离散多轨） | 规模是主因；结构轨只有主链 | 中 |
| Proteina | 规模（5× 参数）+ 合成数据 | 主链 flow matching 本身不新 | 中 |
| La-Proteina | 表征（部分隐变量）+ 数据（AFDB 子集） | 隐变量绕开变长侧链，是架构性的 | 中 |
| Proteina-Complexa | 数据（Teddymer 合成）+ 推理期搜索 | 生成器沿用 La-Proteina；提升主要来自数据与 test-time compute | 中高 |
| AnewOmni | 数据（5M 复合物）+ 统一 block 表征 | 统一表征是架构性的，但多模态数据是主因 | 中 |
| IgGM | 架构（多任务 + consistency）+ 抗体数据 | 残基级，性能受限于无侧链 | 中 |
| BoltzGen | 架构（design as prediction）+ 蒸馏数据 | 把设计重写成预测，是范式性的 | 中高 |
| APM | 架构（侧链扭转角 + 多链） | 无湿实验，指标全是计算代理 | 中低 |

**一句话：2024 年的提升主要来自架构（AF3、RFAA）；2025–2026 年的提升更多来自数据构造（蒸馏、合成复合物、AFDB）与推理期算力（test-time search）。** 不是架构不重要，而是"换架构"的边际收益在下降，"换数据"的边际收益仍然很高。【推断】

**归因的置信度边界（2026-11-10 补）**：上表 13 个模型里有 6 个（ESM3、Proteina、La-Proteina、AnewOmni、IgGM、APM）的置信度只到"中"或"中低"，而"2024 靠架构、2025–2026 靠数据与推理期算力"这条主线正架在这些归因上。支撑它的关键证据本应是"同数据、只换架构"的对照实验，这批论文基本都没做，所以"靠数据"目前是**排除法加相关性推断**：只有当架构解释被排除、或架构沿用而数据同时换过时，增益才记到数据名下，并没有一条"同架构、换数据、指标上升"的因果链。相对可信的是架构替换点可定位、能在同一骨干上指认的那几个——AF3（相对 AF2 换结构模块）、RFAA（残基／原子混合表示）、Chroma（条件机制免重训）、Boltz-1（明确复现、改动可枚举）、BoltzGen（把设计重写成预测）；只能算推测的是骨干沿用而数据同时变化、两栏无法分离的——ESM3（规模与离散表征一起变）、Proteina（5× 参数与合成数据一起变）、La-Proteina（隐变量与 AFDB 子集一起变）、AnewOmni（统一 block 表征与 5M 复合物一起变），以及无湿实验、指标全为计算代理的 APM。这条边界对读者的实际含义是：不要把"2025–2026 靠数据"读成"换架构没用"，它只说明当前这批工作把架构与数据混在一起、无法归因，也不构成"换架构没有边际收益"的证据；要判因果只有三条路——固定数据切点与评测口径只换主干、同一主干喂不同数据配方、或等作者放出可分离的消融。

### 7.2 开放问题

- 侧链的全原子生成仍无低成本、显式、变长方案：Chroma 两段式、La-Proteina 8 维隐变量、AnewOmni block VAE 各自回避了变长侧链自由度，但都引入了新假设（隐式解码可能"补"出看似合理但错误的侧链）。
- 手性与对称性没有成为训练目标：AF3 系自报 4.4% 手性违规；对称性只在 Chroma 里是 conditioner，在 AF3 系里是推理期修正。对抗体／二硫键场景，这是需要单独补模块的地方。
- "全原子"标签仍需逐篇核验（见 7.3 准则）。
- 主干细节披露不均：La-Proteina、SeedProteo、AntiBMPNN 的骨干信息在本次检索中未逐项核实。
- 条件接口与生成器能力的边界：目前多数"条件创新"是 featurizer 层的，真正改变生成器能力的只有原子级配体固定与 atom cross-attention 等少数。

### 7.3 选型时沿用的 5 条硬判据（从底稿准则中抽出）

1. 先问"同切点、同去冗余、同指标"，再看排名。
2. 测试结构发布日期必须晚于训练切点，并做序列／配体／抗原相似度排除。
3. 核验"全原子"标签：是否真的生成侧链原子坐标与原子类型（IgGM／ESM3／La-Proteina 均不满足）。
4. 权重与训练配置是否同时可得（Boltz-1/2、RFAA、IgGM 满足；Chai-1 切点不披露）。
5. 湿实验要问"每靶还是每候选"、筛选通量与阴性对照。

其余 5 条（设计性≠预测精度、归因对照、采样预算归一化、物理有效性单测、抗体克隆级切分）见 `03_评测体系与可复现性.md`。
