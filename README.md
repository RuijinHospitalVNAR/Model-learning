# Model-learning

本仓库用于团队「模型学习」的**记录与分享**：每次学习的讨论内容会被整理成独立篇章沉淀下来，供成员回顾与新成员入门。

## 目录结构

```
Model-learning
├── README.md                 # 本文件：项目说明与学习进程总览
├── 模型篇章/                  # 每个模型一个独立子文件夹
│   ├── <模型名>/README.md     # 该模型的学习记录（依 _TEMPLATE.md 创建）
│   └── _TEMPLATE.md          # 单模型篇章模板
└── 联合分析/                  # 跨模型比较 / 联合使用的分析记录
    └── _TEMPLATE.md          # 联合分析篇章模板
```

## 篇章规范

1. **单模型学习**：在 `模型篇章/` 下新建以模型命名的文件夹，复制 `_TEMPLATE.md` 为该文件夹内的 `README.md` 后填写。
2. **联合分析**：涉及多个模型比较或联合使用的内容，统一放入 `联合分析/`，同样以模板创建，文件名建议为分析主题（如 `A模型与B模型对比.md`）。
3. 篇章内部如需图片、数据等附件，可在对应文件夹内建 `assets/` 子目录存放。
4. 新增或更新篇章后，请同步更新下方「学习进程」表格和「更新日志」。

1. 本地完成一次「模型学习」讨论；
2. 将讨论内容按模板整理为篇章（核心概念、原理、问答精选、心得等）；
3. 提交至本仓库对应目录，并在 README 的「学习进程」表中登记一行。
